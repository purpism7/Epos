# 에포스 전투 — 확정 원리 한 장 (v0 기준 · 2026-11-08)

> **누가 읽나**: 프로그래머(와 그의 AI). 이 문서는 «무엇을 왜 그렇게 하기로 했나»를 전달한다. 수치는 거의 다 임시다 — 수치보다 **원리와 금지선**을 지켜 달라.
> **표시**: 🔵 확정(제제 직접 결정) · 🟡 팀 합의(2026-11-03·11-06 회의 — 확정은 아님) · ⚑ 임시값(시연용 추측, 바뀐다).
> **근거**: 기획자 로컬 프로토타입 «아레나 v0»(브라우저·three.js, 1~11단계)와 설계 볼트의 확정 노트. 다른 게임 이름은 일부러 적지 않았다.

## 0. 한 줄
**기사 3~4명이 성향·임무대로 스스로 싸우고, 플레이어는 설정하고 지켜본다.** 보는 것만으로 재밌어야 한다. 조작은 자동이 재밌어진 뒤에 넣는다. 🔵

## 1. 전투 뼈대 🔵
| 원리 | 규칙 | 왜 |
|---|---|---|
| 자동 전투 | 기본 공격은 자동. 플레이어 입력 없이 한 판이 끝난다(현 단계). | 아이덴티티 = 관전·설정의 재미 |
| 성향 | 기사마다 성향 1개(10종). 성향은 **행동 선택을 기울일 뿐**, 능력치는 바꾸지 않는다. | «왜 저렇게 움직이나»가 읽혀야 함 |
| 3층 설정 | ① 팀 방침 3종(공격형·방어형·유연형) → ② 임무(배치 열·칸이 정함) → ③ 개인 전술(고급: 포커스·값). 성향과 임무가 맞으면 +, 어긋나면 − 를 보여 준다. | 큰 것부터 만지고 작은 것은 나중에 |
| 임무(열별) | 최후열 · 후열 · 전열 · 최전열 4열. 임무 = 선봉장 · 라인 가드 · 수호대 · 사수 · 엄호대 · 사격조율관(🔵) + 돌격대 · 지원 · 후위 요격(⚑). 임무가 **행동 반경과 표적 우선순위**를 정한다. | 배치가 곧 전술 |
| 판단 | 판단 파이프라인 6단계(캐논 동결 2026-06-15). **4단계 = «지금 쓸지, 아낄지»** — 궁극기가 준비됐거나 임박하면 액티브 사용에 기회비용 페널티(판단력 스탯이 관여). 5단계 = 실행 성공 판정, 6단계 = 임시 피로 갱신. | «멍청함»은 버그가 아니라 능력치 차이 |
| 스킬 2종 | 기사마다 **액티브 1 + 궁극기 1**(마나 + 쿨타임). 2차 전직은 패시브 추가(🟡). | 많으면 1초 안에 안 읽힘 |
| 연계기 | 스킬 칸이 아니라 **두 기사의 관계(짝 A×B)에 1건**. 특화 짝(인물 또는 기술 연관)은 특별 연출, 그 밖(관계만 있음)은 범용 연출. | 편성·배치·관계가 재미가 되게 |
| 호응 | A가 궁극기를 쓰는 **순간**, 관계 있는 B가 **근처**(⚑ 3칸)면 **동시에 호응 동작**(B의 궁극기가 아님 · 비용·쿨 0). 타격형 → **따라 찍기**(⚑ 0.5배) · 보호형/특화 → **넓히기**(⚑ 범위 1.5배). 근처에 없으면 안 일어난다. 적은 호응 안 함(현 단계). | 실시간 이동 전투라 궁극기+궁극기 맞추기는 어렵다 |
| 기술 연관 특화 예 | 검 기사가 내려찍으면 마법 기사가 피해 영역을 넓힌다(무속성). 불 속성이면 찍은 자리에 불 피해 + 불 연출(뒤에). | |
| 사망 | **유닛 사망 없음.** HP 0 = 전투 불능. 기사 전원 HP 0 = 던전 공략 실패(장비는 못 가져감 🟡). | |
| 결정론·표현 분리 | **시뮬은 표현을 모른다.** 연출(멈춤·흔들림·넉백 그림·파편·소리)은 전부 표현 계층. 표현용 난수는 시뮬 난수와 분리. 같은 시드 → 같은 결과(해시로 검증). | 리플레이·검증·밸런스의 토대 |

## 2. 클래스 · 무기 🔵 (2026-11-08)
- 원칙: **무기 종류 = 클래스.** 다른 클래스 장비는 착용 불가(🟡). 액션 모션은 클래스 공통, **무기 길이에 따라 속도만 조정**.
- 물리 3: **파이터**(검·방병 — 스몰 쉴드+숏소드 또는 빅 쉴드+롱소드 · 최전열 · 라인) · **랜서**(창병 — 장창 또는 단창 · 전열 · 돌격/우회) · **아처**(궁병 — 단궁 또는 장궁 · 후열 · 사격).
- 그 밖 6계열(마법·보조): 드루이드 · 위저드 · 몽크 · 바드 · 클레릭 · 샤먼 — 총 **9계열**. 1차 직업 = 병사 전용, 2차 세부직업 = 영웅(기사) 전용.
- 상성: 병종 **보병 > 궁병 > 창병 > 보병** · 클래스 **파이터 > 아처 > 위저드 > 파이터**(캐논). 몬스터와의 상성은 속성으로 할 예정(미정).

## 3. 화면 원리 🔵 (기준: «1초 안에 의도를 유추하고 → 세부를 들여다본다»)
- 전투 1초 층 4개: **팀 체력 vs 체력** · **내 기사 3 실루엣+색** · **지금 위험한 한 쌍 선 하나**(= 체력이 가장 낮은 내 기사 ↔ 그를 노리는 적; 없으면 선 0) · **그 순간 배너 하나**.
- 금색은 화면에 한 곳(선택된 전술 · 배너 · 컷인). 배너는 한 번에 하나. 말풍선·의도 글은 4초 유지. 노리는 선은 기본 얇고 옅게.
- 왼쪽 세로 **포트레이트 3** = 스킬 아이콘 2(액티브·궁극기) · 쿨타임 고리 · 준비되면 빛 · 체력 띠 · 짝이 근처면 끈.
- 궁극기 = 왼쪽 위 **포트레이트 컷인** + 말풍선 + 금색 섬광. 호응 기사는 **참여 순서대로 컷인이 쌓이고** 연계 전용 말풍선. 액티브는 머리 위에 **스킬 이름 글자**.
- 결과 창 순서: 승리/패배 → **MVP 크게** → 이긴 이유 3줄 → 결정적 장면(연계 장면 맨 위) → 표 펼치기(기본 3칸 처치·준 피해·생존 → 전부 11칸). 골드 단추는 하나.
- 팀 전술 화면: 왼쪽 방침 카드 3 / 가운데 아군 4열 + 적 격자, 기사 카드 4줄(이름·임무·포커스·열) / 오른쪽 «역할» 판은 **기사를 누르면 펼쳐진다**(열기 2단계 상한) / 아래 레이더(표시만).
- 인카운트(전투 전): 내 기사 4열이 왼쪽, 적은 오른쪽(모든 전투에서 **좌 = 아군, 우 = 적**). 보스는 크게. 유리/비등/불리 막대(⚑). «전투 시작»만 골드.
- 설명 문장·개발 메모는 화면에서 빼고 «?»나 디버그 스위치로만.

## 4. 던전 흐름 🔵 (수치·그림은 껍데기)
첫 화면(기사대전 / 던전 / 던전 이어하기) → 노드맵(육각 칸, **일방통행 — 이긴 칸 잠김, 같은 칸 연속 시도 금지**) → 인카운트(전술 변경 · 편성 · 전투 시작) → 전투(잡몹 · 보스) → 결과 → 전리품 → 장착(무기·갑옷·반지) → 유물 → 다음 칸. 지면 결과 창에 «다시하기»·«물러나기»(⚑ 밸런스 뒤 재결정). 던전 상태는 저장(이어하기). 던전 안에서만 «일시적으로 강해지는 에너지» 컨셉(🟡).

## 5. 타격감(게임 쥬스) 7 — 궁극기·연계기 적중에만 · 전부 표현 계층 🔵
히트 스톱(⚑ 100/140ms, 배속에서 짧아짐) · 피격 하얀 번쩍임 · 넉백(**보이는 밀림만**, 시뮬 좌표 불변) · 효과음 타이밍 + 피치 변동 · 화면 흔들림(강한 공격만) · 파편 + 피해 숫자(연계는 다른 색) · 쇼크웨이브 + **결정타**(판의 마지막 적을 쓰러뜨리는 한 방 = 슬로 + 큰 파동). 7가지 각각 **켬/끔 + 세기(약·중·강)** 매개변수, 게임 안 조절 창.

## 6. 조작 — 나중 🔵 (방향은 정해짐)
- 순서: **자동이 재밌어진 뒤**(기준 통과 + 팀 «재밌다») 조작을 넣는다.
- 조작 기사 = **전투마다 한 명** 고름(전투 중 전환은 미정). 손은 이동·대시·방어·스킬. **기본 공격은 자동** — 무기마다 연타 구성(약-약-약 빠름 / 강-강 넓지만 끝 딜레이)이 **자동으로 이어진다**(버튼 연타 아님). 손을 놓으면 연타 실행, 움직이면 멈춤(🟡 검토).
- 대시 = 조작, MP 없이 **매우 긴 쿨타임**(🟡). 방어 = 일단 기본 조작, 느려지면 스킬(반격·패링)로 교체 검토(🟡 미결). AI도 피할 때·붙을 때 대시(🟡).

## 7. 하지 말 것 🔵
- 표현을 위해 시뮬 로직을 고치지 않는다. 시뮬 난수와 표현 난수를 섞지 않는다.
- 공격 버튼을 반복해 누르는 액션 게임으로 만들지 않는다(기본 공격은 자동).
- 성향으로 능력치를 바꾸지 않는다(성향은 선택만 기울인다).
- 1초 층을 깨는 표시(금색 여러 곳 · 배너 여러 개 · 글자 설명)를 전투 화면에 넣지 않는다.
- 필살기·궁극기의 «아끼는 중» 같은 세부 표시는 Human Gate에서 본 뒤 정한다(지금은 «준비됨» 빛만).

## 8. 임시값 · 미정 ⚑
전부 임시: 스킬 이름(방패 치기·찌르기·얼음 화살) · 쿨타임(6·6·7초) · 아낌 문턱(궁극기 3초 전) · 호응 근처 3칸 · 따라 찍기 0.5배 · 넓히기 1.5배 · 히트 스톱·넉백·흔들림 값 · 유리/불리 식 · 레이더 식 · 전리품·유물 수치 · 말풍선 문구 · 밸런스(기본 편성 100판 아군 58승 — 적은 연계·액티브 없음). 미정: 상성 2층(기사끼리 클래스 / 몬스터 속성) · 인카운트에서 «왜 유리한가» 표시(드래그 배치·상성·표적 선 예정) · 던전 전투 길이(지금 13초쯤 — 연계가 안 보임) · 호응 기사가 실제로 뛰어드는 움직임 · 보호형 궁극기 · 2차 전직 패시브.
