# 팀 회의 요약 한 장 (2026-11-03 화)

> 지위: **🟡 팀 합의 + 미정** — 회의에서 모인 뜻이지 확정(🔵)이 아니다. 근거: 이 회의의 요약본 한 건(짧은 회의 · 참석 제제 · 석환). **말한 사람 표시가 없어** 누구의 말인지 나누지 않았다. 기록에 없는 것은 쓰지 않았다. 작성: 문서 전문가 · 팀장 검수(2026-11-16 — 11-06 원문과 줄별 대조 · 금지어 0건 · 새 🔵 없음)(2026-11-16). 갈음: 없음(첫 판).
> 이름: 석환(조던) = 아트 · 제제 = 기획.
> 쉬운 말 풀이: **스킨갈이** = 부품(파츠)을 갈아 끼워 모습을 바꾸기 · **틴트** = 색을 덧입히기 · **아틀라스** = 그림 조각을 한 장에 모은 묶음 · **배속** = 빠르게 감기.

## 한눈에
1. **전투 방향**은 «속도감 · 연계기 · 필살기 중심 · 기본 자동에서 개인 전술로 깊어지는 구조». 연계기·필살기는 **조건이 맞으면 저절로 발동**하고 수동 사용은 맞지 않는다.
2. **PC 싱글 기준**이라 조작 비중을 높이고, 이후 모바일판은 시뮬레이터·성장 비중을 높인다. 직업은 **16개**가 기본이라는 의견.
3. **아트 파이프라인** 합의가 가장 구체적이었다 — 도트 ✗ · 스파인 경량 · 스킨갈이 · 통 SD · 정면 포트레이트 · 바닥 3D.

## 1. 정해진 것 🟡 (팀 합의 — 확정 아님)
**전투 · 조작**
| 무엇 | 왜 |
|---|---|
| 속도감과 **연계기 · 필살기** 중심으로 간다 | 처음엔 조작할 게 많아 어렵다는 말이 나왔고, 쾌감을 살리자는 쪽으로 모였다 |
| 연계기·필살기는 **트리거 방식**(예: 아군 체력 40%에서 발동 · 근처에서 기다리다 호응해 시너지). **수동 사용은 맞지 않다** | 세트 편성·세트 판매의 가능성도 열린다 |
| 재미 요소 셋: ① 필살기·연계의 쾌감 ② 전술 편성 ③ 유닛·장비 획득 | 기록 그대로 |
| 사용 구조: **기본 자동 설정 → 개인 전술(역할 · 스킬 발동 조건)**로 깊이 들어간다 | 복잡한 세팅과 간편한 조작이 목표 |
| 속도: **기본값은 낮추고 배속(최대 8배)** · 1:1은 빠르게, 대규모는 낮게 · 카메라 연출로 속도감 | 완급 조절 |
| **시끄러운 게임**을 지향 — 말풍선 · 보호·구출 같은 이벤트 표시 · 리플레이 · 외부 토론 유도 | 기록 그대로 |
| PC 싱글 기준이므로 **조작 비중을 높이고**, 모바일판은 시뮬레이터·성장 비중을 높여 수익 방식도 달리한다 | 기록 그대로 |
| 직업은 **4개 대분류 × 근거리/원거리 = 8개 + 전문 직업 2개씩 = 총 16개**가 기본, 계속 늘린다 | 상성·조작 요소는 추가 콘텐츠로 더 얹어도 괜찮다는 의견 |
| 완성도 높은 디테일과 **분량**으로 차별화 | 기록 그대로 |

**캐릭터 · 아트 파이프라인**
| 무엇 | 왜 |
|---|---|
| **도트는 하지 않는다 · 스파인 기반 경량**을 선호 | 가볍게 |
| **스킨갈이**: 직업별 복식 구분 · 갑옷은 하나 · 색 덧입히기 + 망토·헤어 변주 | 파츠 조합으로 종류를 늘린다 |
| 얼굴 파츠(눈·코·입)를 **최대한 세분화** · 포트레이트는 꾸미기 가능 · SD 캐릭터는 **통으로** | 기록 그대로 |
| 유닛 노출 **3단계: 영지 · 방 · 전장** · 아틀라스를 나눠 해상도별 교체 | 용량 |
| 포트레이트는 **정면 고정** · 감정·공용 모션은 따로 · 일러스트는 컷신 위주 | 기록 그대로 |
| 건물·영지는 **바닥을 3D로** | 기록 그대로 |
| 기존 기록 도구 대신 **버전 저장소와 글 파일** 중심으로 정리해 공유 · 일정은 메신저로 확인 | AI로 읽기 쉽게 만들어 공유한다 |
