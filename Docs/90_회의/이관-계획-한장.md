## 5. 위험과 막는 법
- **금지어**: 볼트 노트에 참고작·다른 게임·외부 서비스·코딩 도구 이름, 옛 가칭이 많다 → 장마다 금지어 검색(로마자 낱말 전수 확인 포함) 0건을 확인하고 넘긴다.
- **볼트 안 두 값**: 옛 결정과 새 결정이 한 노트에 함께 있다(예: «영웅이 쓰러지면 대형이 풀린다»(06-03) ↔ «쓰러짐 = 전장에서 빠짐 · 사망 없음»(07-14)) → 합치지 않고 «부딪침»으로.
- **배정표와의 관계**: 배정표(인물 71 · 지역 40 · 기사단 53)는 제제의 작업 도구이고 이미 볼트 값이 들어가 있다 → 인물·기사단 장은 «볼트 확정 값»과 «배정표 값»이 같은지만 대조하고, 다르면 고치지 않고 표로 올린다.
