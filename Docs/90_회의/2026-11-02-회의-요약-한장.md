# 팀 회의 요약 한 장 (2026-11-02 월)

> 지위: **🟡 팀 합의 + 미정** — 회의에서 모인 뜻이지 확정(🔵)이 아니다. 근거: 이 회의의 **요약본과 대화록**(참석 셋 — 대화록의 호칭으로 제제 · 석환 · 승재). 대화록은 자동 받아쓰기라 말한 사람 표시가 없고 오타가 많아, **분명히 읽히는 줄만** 썼다. 요약본과 다른 곳은 «요약과 다름». 작성: 문서 전문가 · 팀장 검수(2026-11-16 — 11-06 원문과 줄별 대조 · 금지어 0건 · 새 🔵 없음)(2026-11-16). 갈음: 없음(첫 판).
> 이름: 석환(조던) = 아트 · 승재(데니스) = 프로그래머 · 제제 = 기획.
> 쉬운 말 풀이: **축소 프로토타입** = 범위를 줄인 시험판 · **오토배틀** = 자동으로 싸우는 방식 · **체인 액션** = 기술이 이어 발동되는 방식.

## 한눈에
1. 현재 시연판은 **전투 규모와 조작이 너무 많아** 복잡하다는 데 셋이 모였다. 그래서 **영웅 3명 · 병사 없음 · 던전 방 이동 · 1~5레벨 초반만** 담은 작은 판을 다시 만들기로 했다.
2. 일정은 «3월 1차 마감»으로 알던 것과 각자 이해가 달랐다. 이 회의는 **방향을 줄이는 회의**였고, 연계기는 «나중에 따로 논의».
3. 가장 큰 숙제는 **누구나 같은 게임을 떠올리게 하는 전달 방식**(글로 남기기)이었다 — 이후 `Docs/`가 그 답이 됐다.

## 1. 정해진 것 🟡 (팀 합의 — 확정 아님)
| 무엇 | 왜 |
|---|---|
| **축소 프로토타입**: 영웅 3명 중심의 작은 던전 전투 · **병사 · 대시 · 패링은 뺀다** · 캐릭터 이동과 기본 명령은 유지 · 1~5레벨 초반 구간을 단계적으로 | 규모·조작이 과하고 «시스템을 펼친 시연»이지 «게임»이 아니었다 |
| 병사가 영웅과 따로 움직이면 복잡하다 → **영웅 중심**으로 함께 움직이는 쪽이 직관적 | 대규모에서는 캐릭터 매력이 약해진다는 우려 |
| 전면 장르 변경은 하지 않는다 — **익숙한 구조에서 덜어내고, 합의된 차별점만 얹는다** | 셋 다 이해하는 게임이어야 빨리 만든다 |
| 기능을 처음부터 다 보이지 않고 **하나씩 익히게** 한다 (레벨이 오르며 열림) | 처음부터 다 열면 어렵다 |
| 사전 세팅으로 전술이 자동 발동하는 재미와 직접 움직이는 참여감을 함께 살리는 방안을 본다 | 조작은 단순하게, 세팅이 결과를 바꾸는 재미 |
| 기존 아트 컨셉은 **유지**, 그래픽 단순화까지는 가능(시각 참고작은 «비주얼 참고»였다) | 컨셉은 이미 셋이 합의했다 |
| **스킬 연계·체인 액션은 초기 검증에서 뺀다** — 프로토타입을 더 키운 뒤 따로 논의 | 지금 구조에 없고, 만들려면 별도 시스템이 필요 |
| 일을 «세 사람이 모두 이해하고 재미있어하는 게임»을 기준으로 한다 · 말과 글을 합의 방식으로 남긴다 | 기획 설명이 한 사람에게 몰려 병목 |

## 5. 요약본과 대화록이 다른 곳
- 요약본은 «참석자 셋 추정»인데 대화록의 호칭은 제제·석환·승재 — **셋이 맞다**.
- 대화록에는 «영웅 3명 + 던전 방 이동 + 병사 뺌 + 대시·패링 뺌»이 더 또렷하다(요약본은 «병사·대시·패링 제외»). 뜻은 같다.
- 큰 차이는 없다. 대화록 중간의 알아볼 수 없는 줄은 쓰지 않았다.
