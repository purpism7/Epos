### 클래스 이름꼴 원칙 (🔵 2026-11-08 제제 채택)
1. **사람을 가리키는 명사 한 낱말** — 파이터 · 아처 · 랜서 · 메이지 · 버서커. 무기 이름 자체(스피어·스태프)나 동작(찌르기)은 이름으로 쓰지 않는다.
2. **성별을 품지 않는다** — «-맨», «-리스/-레스» 같은 꼬리 금지(기사는 여성이 많다). 스피어맨 ✗ · 소서리스 ✗.
3. **짧게(한글 2~4글자)** — 아이콘·카드·말풍선·포트레이트 꼬리표에 그대로 들어가야 한다.
4. **무기나 전장 역할이 바로 떠올라야 한다** — 아처(활) · 랜서(창·돌격) · 메이지(스태프·마법) · 파이터(검·방패·싸움). 원칙 «무기 종류 = 클래스»와 짝이다.
5. **1차 계열과 2차 세부직업은 층이 다르다** — 2차는 우리말 섞인 긴 이름을 허용(화염술사 · 방패기사 · 자연의 수호자). 1차만 이 원칙을 따른다.
6. **바꾸면 옛 이름을 «(옛)»으로 한 번 남긴다** — 레인저 → 슈터 → 아처 · 스트라이커 → 랜서 · 위저드 → 메이지. 코드 식별자는 안 바꿔도 되지만 사람이 읽는 글은 바꾼다.
7. 새 계열(예: 단검 계열)을 열 때는 1~4를 통과하는 후보 2~3개를 먼저 놓고 고른다.
