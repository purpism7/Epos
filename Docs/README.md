## 문서 커밋 규칙 (2026-11-08)
1. 커밋 머리말은 사람 이름 — 기획 문서는 **«[지훈]»**, 프로그래머는 «[승재]». 한 커밋 = 한 주제, `Docs/` 안 파일만.
2. **`--amend` · `rebase` · `reset` 금지** — 고칠 것은 새 커밋으로(여러 세션·사람이 같은 저장소에 커밋한다. 커밋 전 `git log -1`로 HEAD가 내 것인지 본다).
3. 파일을 더하거나 이름을 바꾸면 **이 지도의 표를 같은 커밋에서 고친다**. 지도에 없는 파일은 없는 것.
4. 저장소 루트의 `CLAUDE.md`·`.claude/agents/`는 기획자 AI 세션 설정(팀장 규칙 · 전문가 정의)이다 — 문서 정본이 아니며, 프로그래머가 쓰는 AI도 참고할 수 있다.
