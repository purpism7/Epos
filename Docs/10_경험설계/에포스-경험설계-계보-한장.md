## 0. 한 줄
**최종 목표 = 에포스:무쌍(대규모 전투)** — 수십~수백 명이 전선을 이룬 전장 사이를 «약한 야전 지휘관»인 내가 걸어 다니며, 자리와 순간을 골라 병사에게 전법을, 부관에게 궁극기를 명령해 전황을 바꾼다.
**개발 우선 = 에포스:기사전투(탐사·교전 코어 · 2026-11-08 명명)** — 전투 콘텐츠 = 〈던전(탐사)〉 + 〈기사대전(기사끼리 1대1·3대3 등)〉. 기사 3~4명이 성향·임무대로 스스로 싸우고, 나는 편성·배치·관계를 설계하고 지켜본다. 던전 노드맵을 한 칸씩 나아간다.
**내정(에포스:킹덤)은 한 줄** — 기사단을 경영하는 전투 외 경험(리그·성장·면담 등). 1단계 경험 설계는 마무리 확정, 전투 쪽 뒤에 합쳐진다.

## 1. 계보
| 연구판 | 무엇을 검증하나 | 지위 |
|---|---|---|
| 에포스:킹덤 | 전투 외 경험 — 영주·기사단장의 경영 | 1단계 경험 설계 마무리 확정(2026-10-30) · 2단계 합격 기준 초안 |
| 에포스:무쌍 | **대규모 전투** 경험 — 지휘의 유능함 | 1단계 마무리 확정(2026-10-28) · 2단계 리서치 완료 · **최종 목표 축** |
| 에포스:기사전투 | **소규모 자동 전투 + 던전** — 성향이 읽히는 관전·세팅의 재미 | 2026-11-02 전환 · 아레나 v0 1~11단계 · **개발 우선 축** |
| 세팅 재미 검증판 | 기사 1명 + 디펜스 — 세팅·연타·흐름 실험(갈래) | 연구판 · 결과는 위 둘에 흡수 |

왜 소규모가 먼저인가(🔵): 팀 회의에서 규모·조작 과다, 성향 AI 미구현, «시스템 시연 ≠ 게임»이 문제로 나왔다 → **자동 전투가 재밌는지**는 성향이 눈에 보일 때만 답이 나오므로, 소규모·관전으로 먼저 증명하고 대군·조작은 뒤에 얹는다(순서 변경이지 폐기가 아님 — 무쌍 문서·코드 보존).

## 2. 최종 목표 — 대규모 전투의 경험 (무쌍, 🔵)
| # | 경험 |
|---|---|
| 목표 감정 | «내가 직접 잘 싸우고, 잘 판단하고, 잘 명령했기 때문에 큰 전투력을 움직여 적 전선을 무너뜨렸다.» |
| 최우선 | **내 지휘의 유능함** — 전투를 더 어렵게 해서가 아니라, 좋은 지휘가 어려운 상황을 푼다 |
| 재미의 순간 | 병사·부관에게 직접 명령하고 **그 명령 때문에 전황이 바뀌는 순간** |
| 최상위 판정 | «내 선택 때문에 전투 결과가 달라졌는가? 그 차이를 화면에서 이해할 수 있는가?» — 모든 검증의 질문 |
| 한 사이클 | 자동 기본 공격·위치 선정 → 명령권 획득 → 알맞은 순간 병사 전법(판 만들기) → 적 전선 변화 → 기회 판단 → 부관 궁극기(크게 거두기) → 큰 결과 |
| 지휘관 | **약한 야전 지휘관** — 세지 않다. 기본 공격은 자동, 손은 이동·위치·명령에 |
| 전법 3종 | 돌파 · 방진 · 집결(함성) — 명령권과 별도 축 |
| 명령 단위 | 분대(RTS식 개별 지시 금지) · 병사 = 소모품(야전 중 보충 없음) |
| 대군 속 개입 | «지휘관을 따라다니는 병사 3명»이 최종이 아니다 — 이미 전선을 이룬 수십~수백 명 사이를 걸어 다니며 필요한 곳에 개입 |
| 클래스 = 무기 타입 | 기사 종류의 가장 큰 구분은 무기(이름·초상화가 나머지를 구분) |
| 적 기사 | 격파는 결정타 시네마틱 · 위협은 예고된다 · 표적 정책은 «둘레 안 가장 가까운 적»(지휘관 우대 없음) |

## 3. 개발 우선 — 소규모 전투의 경험 (🔵, ⚑ 표시)
| # | 경험 |
|---|---|
| 한 줄 | 정식 에포스의 **탐사·교전 코어**를 먼저 검증한다. 초점 = 소규모 부대 전술(자동 전투) 구성 |
| 구조 | 노드맵 한 칸씩 → 칸마다 사건 → 전투 칸은 자동 전투 → 파티 기사 **3~4명** |
| 바라는 것 ① | **성향이 다른 기사들이 서로 다르게 싸우는 모습이 설명 없이 읽힌다** — 같은 적을 두고 누구는 뛰어들고, 누구는 물러서고, 누구는 동료를 감싼다 |
| 바라는 것 ② | 보는 것만으로 재밌다 — «얘는 이래서 이렇게 움직였구나»(⚑) |
| 바라는 것 ③ | 이기고 지는 이유가 결과 창에서 읽힌다(MVP · 이긴 이유 · 결정적 장면)(⚑) |
| 바라는 것 ④ | **세팅이 결과를 바꾼다** — 누구를, 어떤 성향 조합으로, 어디에 세우나 · 누구와 짝인가(연계) |
| 플레이어가 하는 것 | 전투 전 = 편성·배치·3층 설정 / 전투 중 = 방침 3종 전환 · 보기 도구(배속·일시정지) / 직접 조작 = **없음(보류 → 자동이 재밌어진 뒤)** |
| 한 판 | 3 vs 3(4 vs 4 스위치) · 작은 경기장 한 화면 · 30~60초(⚑) · 끝 = 전멸 또는 시간 뒤 체력 비율 |
| 스킬·연계 | 액티브 1 + 궁극기 1 · 연계기 = 짝(A×B) · 호응 동작 · 기사가 스스로 쓴다(성향에 따라 때가 다름) |
| 던전 | 잡몹 → 보스 · 전리품 → 장착 → 유물 · 이긴 칸 잠김 · 일시적으로 강해지는 에너지(🟡) · 사망 없음(HP 0 = 불능) |
| 화면 | 왼쪽 = 아군 · 오른쪽 = 적(모든 전투) · 1초 층 4개 · 금색 한 곳 · 배너 하나 |
| 합격 기준 | H-1 «딱 보기에도 재밌고, 하기 쉽다» · H-2 «1초 안에 의도를 유추하고 → 세부를 들여다본다» |
| 네 층 | 손맛 · 읽힘 · 흐름 · 덜어내기 — 층마다 «목표 한 줄»을 두고 검증 |

## 4. 둘을 잇는 것 · 다른 것
| 이어지는 것(공통 🔵) | 다른 것 |
|---|---|
| 기본 공격은 자동 · 버튼 연타 게임이 아님 | 무쌍: 병사·분대·전법·명령권 있음 / 소규모: 병사 없음 |
| 클래스 = 무기 종류 · 9계열 · 병종 상성 | 무쌍: 플레이어 지휘관이 걸어 다님(조작) / 소규모: 조작 없음(뒤에 «전투마다 기사 한 명») |
| 스킬 2종(액티브·궁극기) · 아낌 판단 · 성향은 선택만 기울임 | 무쌍: 전황·군세 읽기 / 소규모: 성향·관계 읽기 |
| 결정론 · 표현 분리 · 적 위협은 예고 · 결정타 시네마틱 | 무쌍: 60초 종료·군세 판정 / 소규모: 30~60초·체력 비율 |
| 참고작 수치는 정답이 아니다 · 외부 공유 전 이름·자료 교체 | |

## 5. 하지 말 것 (두 판 공통 🔵)
- 혼자 천 명을 베는 딜러 · 공격 버튼 연타.
- RTS식 병사 개별 지시 · 병사 수 비례 비용.
- 전투를 더 어렵게 해서 긴장을 만드는 것(좋은 지휘·세팅이 해결하게).
- 성향이 능력치를 바꾸는 것.
- 새 붕괴 게이지·상태를 임의로 확정하기(사기·동요·패주는 별도 설계 뒤).
- 참고 자료의 수치를 규칙의 정답으로 쓰기 · 외부 공유 전 교체 없이 남기기.
- (대규모) 지휘 없이 이기는 자동 전투 — 명령 0으로는 못 이긴다.

## 6. 검증 방식
- **Human Gate**: 기획자 혼자, 설명 글 없이 플레이 → 그 회차의 «볼 곳 5줄»에 1~5점 + 이유. 밖의 발견은 보류함에 적기만.
- 판정 질문은 늘 하나: «내 선택(세팅·명령) 때문에 결과가 달라졌고, 그 차이가 화면에서 읽히는가».
- 조작 착수 조건: H-1 통과 + 팀이 자동 판에 «재밌다».
