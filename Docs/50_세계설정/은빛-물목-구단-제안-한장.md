# 은빛 물목의 구단과 경기장 — 제안 한 장 (2026-11-24 ⚑ 제안)

> 지위: **⚑ 제안 — 제제가 고르기 전 · 정본 아님.** 테두리는 `은빛-물목-리그-한장.md`의 🔵 줄이고(바꾸지 않았다), **이 장의 구단 이름 · 상징 · 색의 느낌 · 역사 · 맞수 · 경기장은 모두 메인 컨셉 세션이 지은 것(⚑)**이다. 작성: 메인 컨셉 디자인 세션 · 팀장 검수(2026-11-24 — 금지어 · 실제 구단과 리그 이름 0건 · 여섯 가칭이 기존 기사단 · 지명과 겹치지 않음 · 기존 기사단을 엮지 않음 · 강가 경기장은 여섯 가운데 하나뿐임 확인).
> 요약 3줄: ① 리그 크기는 **작게(동 3 + 서 3 = 6)** / **넉넉하게(동 6 + 서 6 = 12)** 두 안 — 표는 6구단만 채웠다. ② 여섯 구단은 **깃발의 바탕 꼴이 서로 다르고**(엇갈린 선 · 아치 · 십자 · 마름모 · 세모 · 세로 줄), 맞수의 선이 여섯 가닥 있다. ③ 상징 경기장은 **강 한가운데 섬의 둥근 경기장** — 어느 구단의 것도 아닌 자리로 제안한다.
> 지킨 것: 기존 기사단 53곳은 건드리지 않았고 엮지 않았다 · 종족은 붙이지 않았다(여러 땅 사람이 섞인 곳으로 둠) · 실제 구단 · 리그 · 도시 · 다른 게임의 이름은 쓰지 않았다(맞수는 «꼴»만) · 색은 이름을 못 박지 않고 **느낌**만 적었다(고르는 것은 석환).
> ⚑ 읽기 하나: 🔵는 «물길을 가운데 두고 동부와 서부»까지다. 이 장은 그리기 쉽게 «강의 동쪽 기슭 = 동부 · 서쪽 기슭 = 서부»로 **읽고** 본거지를 놓았다 — 정해진 것이 아니다.

## 1. 리그의 크기 — 두 안 (⚑)
| | 안 가 — 작게 시작(동 3 + 서 3 = **6**) | 안 나 — 리그답게(동 6 + 서 6 = **12**) |
|---|---|---|
| 얻는 것 | 마크 · 유니폼이 6벌 — 석환이 한 구단씩 공들일 수 있다 · 여섯 이름을 유저가 다 외운다 · 맞수 선이 모두 굵다 | «왕국에서 가장 큰 리그»(🔵)가 숫자로 느껴진다 · 순위표가 길어 오르내림이 생긴다 · 맞수 꼴을 더 많이 쓸 수 있다 |
| 잃는 것 | 한 리그에 상대가 둘뿐 — 한 철이 짧고 «가장 큰 리그»로는 작아 보인다 | 그릴 것이 두 배 · 비슷한 구단이 생기기 쉽다 · 깃발 꼴 12가지를 작게도 읽히게 가르기 어렵다 |
| 첫 판에 필요한 최소 | 6 가운데 **유저 쪽 리그의 3**만 있어도 한 철이 돈다 | 12를 다 채우기 전에는 «빈 자리가 많은 리그»로 보인다 |
- ⚑ 추천: **안 가로 시작하고, 자리는 12칸으로 잡아 둔다**(«올해는 여섯, 리그는 자란다»). 아래 표는 6구단만 채웠고 나머지는 4절 끝에 «이어서» 자리만 남겼다.

## 2. 구단 표 (모두 ⚑ — 이름은 가칭)
> 읽는 법: 색 칸은 **느낌**이다. 편 구분 색(🔵 아군 파랑 · 적군 빨강 · 지원 초록 · 중립 노랑)은 옷 위에 따로 얹으므로, 구단 바탕색이 이 네 원색과 같으면 편 표시가 묻힌다 — 그래서 여섯 구단 모두 **원색에서 비켜난 색**(바랜 색 · 섞인 색 · 무채색)으로 잡았다.

### 동부 ① 맏나루 기사단 (또는 «첫닻 기사단»)
| 칸 | 내용(⚑) |
|---|---|
| 본거지 | 동쪽 **강가** — 은빛 물목에서 가장 오래된 옛 나루터 |
| 한 줄 정체성 | «이 강에 처음 깃발을 꽂은 건 우리다» — 뱃사공 집안이 대대로 응원하는 맏이 구단 |
| 상징 | **엇갈린 노 두 자루**(× 꼴) · 색의 느낌 = 젖은 나무의 짙은 밤빛 + 낡은 밧줄의 바랜 흰빛(따뜻하고 어두움) |
| 유니폼 | 경갑의 어깨끈을 **밧줄 매듭**으로 묶는다 · 새 옷도 일부러 물 빠진 듯한 천 |
| 역사 · 맞수 | 리그가 생길 때부터 있던 옛 명문 — 요즘은 우승이 뜸하다. **겹다리**(갈라져 나간 식구) · **은등**(새로 일어선 구단)과 맞수 |
| 팬 · 응원 | 노 젓는 구령 같은 낮은 합창 · 할머니와 손녀가 같은 자리에 앉는다 |
| 동기부여 | «옛 이름만 남은 구단»이 아님을 증명한다 |

### 동부 ② 겹다리 기사단 (또는 «돌아치 기사단»)
| 칸 | 내용(⚑) |
|---|---|
| 본거지 | 동쪽 **도심** — 겹다리 다리목의 시장 거리 한복판 |
| 한 줄 정체성 | «배를 기다리지 않는다, 우리는 건너간다» — 짐꾼과 수레꾼의 구단 |
| 상징 | **겹친 아치 둘**(∩∩ 꼴) · 색의 느낌 = 구운 벽돌의 주황 흙빛 + 크림빛(따뜻하고 중간 밝기 — 빨강 쪽으로 기울지 않게) |
| 유니폼 | 짐을 메던 버릇대로 **한쪽 어깨만 두꺼운** 어깨받이 · 짧은 조끼 |
| 역사 · 맞수 | 다리가 놓이자 «다리가 나루를 죽인다»는 다툼 끝에 **맏나루에서 갈라져 나온** 짐꾼들이 세웠다. 두 구단의 경기는 한 동네가 둘로 갈리는 날 |
| 팬 · 응원 | 발 구르기 — 다리가 울리듯 관중석이 울린다 · 시장 상인들이 가게 문을 닫고 온다 |
| 동기부여 | «갈라져 나온 쪽»이 아니라 «앞서 나간 쪽»임을 증명한다 |

### 동부 ③ 물레둑 기사단 (또는 «방아돌 기사단»)
| 칸 | 내용(⚑) |
|---|---|
| 본거지 | 동쪽 **외곽** — 물레방아와 창고가 줄지은 강둑 너머 들녘 가장자리 |
| 한 줄 정체성 | «화려하진 않아도 끝까지 돈다» — 방앗간 일꾼들의 끈질긴 구단 |
| 상징 | **날개 넷 달린 물레**(＋ 꼴 — 둥근 테를 두르지 않는다) · 색의 느낌 = 바랜 밀빛 + 방아돌의 잿빛(따뜻하고 밝음 — 노랑 원색보다 훨씬 바래게) |
| 유니폼 | 소매를 걷어 올린 꼴 · 앞치마 같은 **허리 덮개** |
| 역사 · 맞수 | 가문 여름에 수문이 닫혀 물레가 멈춘 «마른 여름»을 아직도 말한다 — 물을 **쓰는** 쪽과 **여닫는** 쪽, **윗수문**과 자존심의 맞수. 같은 동부의 겹다리와는 «일터 대 장터»의 작은 앙금 |
| 팬 · 응원 | 응원가가 하나뿐이고 끝없이 돌려 부른다 · 지고 있어도 자리를 뜨지 않는다 |
| 동기부여 | «큰 구단의 들러리»가 아님을 — 마지막까지 버티는 쪽이 이긴다는 것을 증명한다 |

### 서부 ④ 은등 기사단 (또는 «밤물결 기사단»)
| 칸 | 내용(⚑) |
|---|---|
| 본거지 | 서쪽 **도심** — 밤마다 등이 켜지는 유람 거리(강에서 한 골목 안쪽) |
| 한 줄 정체성 | «오늘 밤 가장 빛나는 곳» — 새 돈과 새 별이 모이는, 리그에서 가장 화려한 구단 |
| 상징 | **등불 하나**(◆ 마름모 꼴) · 색의 느낌 = 밤빛 보라 + 은빛(차갑고 어두움에 반짝임) |
| 유니폼 | 은실 자수 한 줄 · 가볍고 **긴 망토 자락** — 움직일 때 가장 예쁜 옷 |
| 역사 · 맞수 | 가장 늦게 생겼고 가장 빨리 강해졌다 — 이름난 기사를 큰돈으로 데려온다는 말을 듣는다. **맏나루**(옛 명문)와는 «전통 대 새 힘», 이웃 **흰돛**과는 «누가 서부의 얼굴인가» |
| 팬 · 응원 | 등불 물결 · 악단 · 귀한 손님 자리 — 처음 온 관광객도 따라 할 수 있는 쉬운 응원 |
| 동기부여 | «돈으로 산 구단»이 아니라 실력으로 선 구단임을 증명한다 |

### 서부 ⑤ 흰돛 기사단 (또는 «먼돛 기사단»)
| 칸 | 내용(⚑) |
|---|---|
| 본거지 | 서쪽 **항구 쪽** — 큰 배가 닿는 하류의 부두 끝 |
| 한 줄 정체성 | «배를 대는 곳이 우리 집» — 어디든 따라가는, 원정 응원이 가장 큰 구단 |
| 상징 | **세모 돛 하나**(▲ 꼴 — 한쪽으로 기운 세모) · 색의 느낌 = 돛의 흰빛 + 노을의 살구 · 분홍빛(밝고 따뜻함) |
| 유니폼 | **한쪽 어깨에만 걸친 돛천 망토** · 발목이 드러나는 가벼운 차림 |
| 역사 · 맞수 | 먼 물길을 다니던 뱃사람들이 세웠다 — 서부의 주인은 원래 자기들이었다고 믿는다. 뒤늦게 온 **은등**에게 손님과 이름을 빼앗겼다고 여긴다 |
| 팬 · 응원 | 응원단이 **배를 타고** 남의 경기장에 들어간다 · 돛천 깃발을 머리 위로 넘긴다 |
| 동기부여 | 화려함이 아니라 «멀리 가 본 쪽»이 강하다는 것을 증명한다 |

### 서부 ⑥ 윗수문 기사단 (또는 «흰수문 기사단»)
| 칸 | 내용(⚑) |
|---|---|
| 본거지 | 서쪽 **언덕** — 층층 수문 위, 수도가 올려다보이는 흰 돌 언덕 |
| 한 줄 정체성 | «강을 여는 것은 우리다» — 수문지기의 격식과 자부심, 수도의 손님이 찾는 구단 |
| 상징 | **세로 줄 셋**(수문의 문살 — ┃┃┃ 꼴) · 색의 느낌 = 물때 낀 청동의 청록빛 + 흰 돌빛(차갑고 중간 밝기 — 파랑과 초록 사이라 **두 원색에서 가장 조심해서 떼어야 하는 색**) |
| 유니폼 | 깃이 높고 반듯한 옷 · 놋쇠 단추 — 경갑인데도 **예복처럼** 보인다 |
| 역사 · 맞수 | 수문을 여닫는 일이 곧 왕국의 일이라는 자부심 — 다른 구단을 «아랫물»이라 부르다 미움을 샀다. **물레둑**과 «마른 여름»의 맞수, **은등**과는 «격식 대 화려함» |
| 팬 · 응원 | 박수와 종소리 — 소리 지르지 않는 응원 · 경기 전 수문을 여는 의식 |
| 동기부여 | 격식이 겉멋이 아니라 «흔들리지 않는 힘»임을 증명한다 |

## 3. 맞수 관계 그림 (⚑)
```
        [서부]                          [동부]
   ⑥ 윗수문 ════ 마른 여름(쓰는 쪽 대 여닫는 쪽) ════ ③ 물레둑
       │ 격식 대 화려함                              │ 일터 대 장터(작은 앙금)
   ④ 은등 ═════ 전통 대 새 힘(옛 명문 대 새 구단) ═══ ① 맏나루
       ║ 누가 서부의 얼굴인가                        ║ 갈라진 식구(나루 대 다리)
   ⑤ 흰돛                                        ② 겹다리
```
| 선 | 누구와 누구 | 맞수의 꼴 | 굵기 |
|---|---|---|---|
| 1 | 맏나루 ↔ 겹다리 | 한 동네의 두 구단 · 한때 한 구단이었다 갈라진 사이 | 굵음(동부의 큰 경기) |
| 2 | 은등 ↔ 흰돛 | 이웃의 오랜 주인과 새로 온 강자 | 굵음(서부의 큰 경기) |
| 3 | 맏나루 ↔ 은등 | 옛 명문과 새로 일어선 구단 | 굵음(리그를 넘는 선) |
| 4 | 물레둑 ↔ 윗수문 | 강을 사이에 둔 · 서로 다른 일을 하던 무리의 자존심 | 굵음(리그를 넘는 선) |
| 5 | 윗수문 ↔ 은등 | 격식 대 화려함 | 가늚 |
| 6 | 겹다리 ↔ 물레둑 | 장터와 일터의 앙금 | 가늚 |
- 리그를 넘는 선(3 · 4)이 **어디서 맞붙는지**는 컵 대회의 꼴이 정해져야 한다(없음 — 정해야 함). 맞수가 없는 구단은 없다.

## 4. 동부와 서부의 결 (⚑ — 제제의 인상을 우리 세계의 말로)
> 제제의 인상(정한 것 아님): 서부 = 화려한 시설 · 유명인과 관광객 / 동부 = 현지의 오랜 팬. 색으로 가르지 않는다(파랑 · 빨강은 편 구분 색).

| 가르는 것 | 동부 — «일하는 기슭» | 서부 — «손님 맞는 기슭» |
|---|---|---|
| 한 줄 | 나루 · 다리목 · 방앗간 — 강에서 **일하는** 사람들의 동네 | 유람 거리 · 큰 부두 · 흰 수문 — 강을 **보러 오는** 사람들의 동네 |
| 건물의 결 | 젖은 나무 · 구운 벽돌 · 낮고 빽빽한 지붕 | 흰 돌 · 등불 · 높고 넓은 마당 |
| 깃발의 꼴 | **세로로 길고 끝이 두 갈래**(나루 장대에 매던 꼴) | **가로로 넓고 아래에 술**(잔칫날 내거는 꼴) |
| 응원 | 구령 · 발 구르기 · 대대로 같은 자리 | 등불 · 악단 · 종소리 — 처음 온 손님도 낀다 |
| 관중 | 동네 사람 · 일 끝나고 온 차림 | 먼 데서 온 손님 · 차려입은 차림 |
- 깃발의 꼴만 봐도 동부 / 서부가 갈리면, 작은 전장 캐릭터(🔵 5-1 · 5-2)에서도 «바탕 꼴(동서) + 가운데 마크(구단)» 두 겹으로 읽힌다.
- **이어서(안 나로 넓힐 때의 빈 자리 · 이름은 짓지 않음)**: 동부 3 — 상류 숲가 · 들판으로 가는 길목 · 배 시장 / 서부 3 — 하구의 갯마을 · 언덕 위 새 주택가 · 수도 쪽 관문 앞.

## 5. 경기장 자리 (⚑ — 강가는 여섯 가운데 하나뿐 · 🔵 «모든 경기장을 강에 두지 않는다»)
| 구단 | 자리 | 한 줄 |
|---|---|---|
| ① 맏나루 | 강가 | 옛 나루 창고를 고쳐 쓴 낡고 가파른 경기장 — 관중석이 싸움터에 바짝 붙어 있다 |
| ② 겹다리 | 도심 | 시장 집들 사이에 끼어 있어 지붕 위에서도 구경한다 |
| ③ 물레둑 | 외곽 | 들녘 가장자리의 흙 둔덕 관중석 — 뒤로 물레방아가 돈다 |
| ④ 은등 | 도심(유람 거리) | 지붕 테두리에 등 수백 개가 달린 리그에서 가장 새 경기장 |
| ⑤ 흰돛 | 항구 쪽 | 부두 끝 — 관중석 너머로 돛대 숲이 보인다 |
| ⑥ 윗수문 | 언덕 | 흰 돌 언덕 꼭대기 — 수문과 강이 내려다보이고 수도가 올려다보인다 |

## 6. 은빛 물목의 상징 경기장 (⚑ — 🔵 «하나를 만든다 · 강을 낀 경기장 장면의 에센스»)
| 칸 | 내용(⚑) |
|---|---|
| 가칭 | **물목 큰마당** · 두 기슭 경기장 · 은물결 둥근마당 |
| 자리 | **강 한가운데의 섬** — 동쪽 기슭과 서쪽 기슭에서 다리가 하나씩 놓인다. 어느 구단의 홈도 아닌 **모두의 경기장** |
| 겉모습 | 콜로세움 같은(🔵) 둥근 경기장 — 아치가 세 층으로 쌓이고 지붕은 없다. 꼭대기 테두리에 구단 깃발이 빙 둘러 꽂힌다 |
| 재질 | 수문과 같은 **흰 돌** · 물에 닿는 아래층은 물때가 낀 짙은 돌 · 깃대와 난간은 젖은 나무 |
| 강과 만나는 법 | 맨 아래층 아치가 **물 문**이다 — 배가 아치 밑으로 들어와 경기장 안 선착장에 닿는다 |
| 관중 | 동쪽 팬은 동쪽 다리, 서쪽 팬은 서쪽 다리로 걸어 들어와 **자기 기슭 쪽 절반**에 앉는다 · 원정 응원단은 배로 물 문에 닿는다 · 못 들어온 사람은 다리와 배 위에서 본다 |
| 낮과 밤 | 낮 = 물빛이 흰 벽에 일렁이고 눈부시다 / 밤 = 아치마다 등이 켜지고, 이긴 편 팬이 강에 등을 띄운다 |
| 무엇이 열리나 | ⚑ 컵 대회의 결승 · 동부 으뜸과 서부 으뜸이 만나는 한 판 · 철을 여는 날의 잔치(컵의 꼴은 정해지지 않았다) |
| 한 장면으로 | 강 하류에서 올려다본 구도 — 가운데 흰 둥근 경기장, 양쪽으로 뻗은 두 다리에 깃발 든 사람의 줄, 앞쪽 물 위에 응원단의 배, 멀리 뒤로 수도의 탑 |

## 7. 석환에게 넘길 때의 한 줄 요약표 (⚑ — 로고 작업의 출발점)
| 구단 | 리그 · 깃발 바탕 | 상징의 형태 | 색의 느낌(이름은 석환이 고른다) | 한 낱말 |
|---|---|---|---|---|
| ① 맏나루 | 동부 · 세로 두 갈래 | × 엇갈린 노 | 짙은 밤빛 나무 + 바랜 흰 | 전통 |
| ② 겹다리 | 동부 · 세로 두 갈래 | ∩∩ 겹친 아치 | 주황 흙빛 + 크림 | 억셈 |
| ③ 물레둑 | 동부 · 세로 두 갈래 | ＋ 날개 넷 물레 | 바랜 밀빛 + 잿빛 | 끈기 |
| ④ 은등 | 서부 · 가로 술 | ◆ 등불 | 밤빛 보라 + 은빛 | 화려 |
| ⑤ 흰돛 | 서부 · 가로 술 | ▲ 기운 세모 돛 | 흰 + 노을 살구 · 분홍 | 떠돎 |
| ⑥ 윗수문 | 서부 · 가로 술 | ┃┃┃ 세로 줄 셋 | 청동 청록 + 흰 돌 | 격식 |
- 여섯 형태는 **윤곽만으로 갈린다**(선 둘 · 굽은 선 · 십자 · 마름모 · 세모 · 줄 셋) — 깃발이 손톱만 해도 읽히게 하려는 뜻이다. 안을 채우는 무늬 · 글자는 넣지 않는 쪽을 권한다.
- 석환에게 물을 것: ① 이 여섯 꼴이 작은 깃발에서 실제로 갈리나 ② 색의 느낌 가운데 편 구분 색과 헷갈리는 것(특히 ⑥ 청록 · ③ 밀빛 · ② 주황 흙빛) ③ 기존 문양(국교의 백화 = 빛나는 구체 + 세 갈래 불꽃)과 닮아 보이는 것이 있나.

## 8. 제제에게 물을 것 (취향 · 방향만)
1. **리그의 크기** — (권장) 여섯으로 시작하고 자리는 열두 칸 · 처음부터 열둘. 얻는 것 / 잃는 것은 1절.
2. **상징 경기장은 누구의 것인가** — (권장) 어느 구단의 것도 아닌 강 가운데 섬(큰 경기만 열림) · 한 구단의 홈(그 구단이 «리그의 얼굴»이 된다 — 대신 나머지가 손님처럼 보인다).
3. **유저의 구단** — (권장) 여섯과 따로 **일곱 번째 새 구단**을 유저가 세운다(맞수들 사이에 끼어드는 새내기) · 여섯 가운데 하나를 맡는다(역사와 맞수를 물려받는다 — 대신 유저가 고르지 않은 색과 이름을 입는다).
4. (의외) **구단에 종족의 결을 입힐까** — (권장) 입히지 않는다(은빛 물목은 여러 땅 사람이 섞인 곳) · 한두 구단에만 입힌다(한눈에 갈리지만, 종족이 정해진 기존 기사단과 겹쳐 보일 수 있다).
