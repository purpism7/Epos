# 수도의 남쪽 관문 — 후보안 세 가지 (2026-11-23 ⚑ 제안)

> 지위: **⚑ 제안 — 제제가 고르기 전 · 정본 아님.** 🔵 «수도의 남쪽 관문을 새로 만든다»(제제 2026-11-23 · `지역-지명-한장.md` 3절)를 받아, 고를 재료로 세 안을 지었다. **1절만 근거 문서의 말이고, 2절부터는 모두 메인 컨셉 세션이 지은 것(⚑)이다.** 🔵는 하나도 바꾸지 않았다. 작성: 메인 컨셉 디자인 세션 · 팀장 검수(2026-11-23 — 금지어 0건 · 1절의 근거 줄 표본 대조 · 내용은 고치지 않음).
> 요약 3줄: ① 지금 문서에는 남쪽에 대한 줄이 **없다** — 남쪽에 놓아도 어긋나는 줄도 없다. ② 세 안 = **물길의 나루 도시 / 볕드는 순례 비탈 / 왕국 끝의 큰 성문**. ③ 제제가 정할 것은 «새벽의 들판과 닮은 이웃인가, 뚜렷이 다른 땅인가»가 먼저다.
> 구단(이름 · 색 · 마크)은 짓지 않았다 — 구단이 놓일 **자리**만 적었다. 색 칸은 석환이 떠올릴 낱말이지 정한 색이 아니다.
> **고름(🔵 제제 2026-11-23)**: **안 1 «물길의 나루 도시»의 결로 간다 — 별명은 «은빛 물목».** ① 수도의 **남쪽에 새 지역을 두고 만든다** — 지역 별명 = **«은빛 물목»**(남쪽 관문 제안의 안 1 «물길의 나루 도시»에서 고른 이름). ② **큰 물줄기**가 수도 아리아델에서 «상인들의 거처»로 이어진다 — 이 큰 강을 중심으로 경제가 활발해, **왕국에서 가장 큰 리그를 가진 지역**이다(제제: «타당성이 생긴다»). ③ 물길을 가운데 두고 **동부와 서부로 나눈다** — 프로 농구 리그처럼 **동부 리그 · 서부 리그**, 그리고 **컵 대회**가 있다. ④ **구단식 기사단은 이 지역에 새로 만든다.** 기존 기사단들은 건드리지 않는다(11-22 결정 그대로). 안 2 · 안 3은 고르지 않았다(남겨 둔 재료). 안 1의 표에 적힌 풍경 · 먹을거리 · 행사 · 이름 후보의 나머지는 여전히 ⚑ 재료다. 안 1의 «어긋날 수 있음»(배와 운송이 상인들의 거처와 겹침)은 «강이 상인들의 거처로 이어진다»는 결정으로 **겹침이 아니라 이어짐**이 됐다.

## 1. 지금 문서가 남쪽에 대해 말하는 것
| 물음 | 문서의 줄 | 근거 |
|---|---|---|
| 남쪽이 적힌 줄 | **없음** — 방위가 적힌 것은 «광휘의 수도 **동쪽** 관문»(새벽의 들판) · «세계관 **북쪽**»(서리의 성채) · «왕국의 **동쪽** 거대 해협 건너»(환요대륙)뿐 | 지명 1절 13 · 19 · 39번, 3절 |
| «관문»이란 | 새벽의 들판은 관문에 놓인 **넓은 땅이자 큰 도시**이고, 그 너머 땅(울창한 그늘)으로 가는 **길목**이다 → 남쪽 관문도 «문 하나»가 아니라 «문 앞의 땅 + 그 너머로 가는 길목»으로 읽을 수 있다(⚑ 읽기) | 지명 1절 13번 |
| 수도 둘레의 물 | 수도 **외곽**에 늘 잔잔한 «거울의 호수», 중심부에 «반짝이는 샘» — 어느 쪽 외곽인지, 물이 어디로 흐르는지는 없음 | 지명 1절 7 · 11번 |
| 수도의 길과 문 | 순례길 «빛의 길»(개선문 «광화문»과 대성전 둘레를 이음) — 전대 여왕이 계시를 이행하고 **돌아온** 일을 기림. 어디서 돌아왔는지 · 문이 어느 쪽을 보는지는 없음 | 지명 1절 5 · 6번 |
| 수도와 다른 땅 사이 | 상인들의 거처 = «주요 지역과 수도 **사이**에 놓인 무역도시»(해안선이 있음) · 그곳 기사단이 «대륙 횡단 및 해로 운송»을 지킴 — 방위는 없음 | 지명 1절 34 · 35번 · 기사단 정리 «거래수호» |
| 왕국 밖의 땅 | 가장 어두운 모래 = «왕국 비복속 연합국가» · 미르코 제국 = 다른 나라 — 둘 다 방위 없음 | 지명 1절 29번 · 왕국-주인공 1-10 |
| 기후의 단서 | 북쪽 = 혹한. «남쪽은 따뜻하다»는 줄은 **없음**(⚑ 읽기로만 씀) | 지명 1절 19번 |
- 정리: **남쪽 자리는 비어 있다.** 방위가 없는 땅(상인들의 거처 · 미식룡의 인정 · 찬란한 수평선 · 바람의 협곡 · 불타는 뼈 산 · 가장 어두운 모래)은 어느 것도 «남쪽 너머»에 놓아도 문서와 부딪치지 않지만, 놓으라는 줄도 없다 — 세 안은 **너머의 땅을 못 박지 않는다.**
- 이름의 결(⚑ 읽기): 지금 지명은 «꾸밈말 + 지형»(새벽의 들판 · 울창한 그늘 · 서리의 성채 · 거울의 호수)이다. 동쪽이 «새벽»이라 남쪽에 «한낮»을 이어 본 이름을 안마다 하나씩 넣었다(«노을»은 서쪽을 위해 남겨 둠).

## 2. 후보안 (모두 ⚑ — 지은 것)

### 안 1 — 물길의 나루 도시 · «들판은 땅길, 여기는 물길»
| 칸 | 내용(⚑) |
|---|---|
| 가칭 | **한낮의 나루** · 잔물결 나루 · 은빛 물목 |
| 한 줄 분위기 | 수도의 물이 흘러내려 큰 강이 되는 곳 — 배와 다리와 사람 소리로 늘 시끌벅적한, 왕국에서 가장 **활기찬** 문 |
| 대표 풍경 | ① 층층이 물을 가두는 흰 돌 **수문**과 그 위의 겹다리 ② 강에 떠 있는 **배 시장**(천막 친 나룻배들) ③ 강둑의 물레방아와 창고 줄 ④ 한낮 볕이 수면에 부서지는 넓은 강 |
| 색 · 빛 · 날씨 | 물빛 · 흰 돌 · 젖은 나무 · 눈부신 한낮의 반짝임 / 맑고 물기 많음 · 짧은 소나기 뒤 무지개 |
| 사는 이 | 뱃사공 · 짐꾼 · 수문지기(종족은 짓지 않음 — 여러 땅 사람이 오가는 곳) |
| 먹을거리 · 소품 | 민물고기 꼬치 · 강바람에 말린 국수 / 노 · 밧줄 · 뱃머리 등 · 수문 손잡이 바퀴 |
| 행사 | 나룻배 겨루기 · 밤에 강에 등 띄우기 |
| 이웃과의 관계 | 수도: 물을 받아 내려보냄 · 새벽의 들판: 들판의 곡물 · 우유가 여기서 배에 실린다(**돕는 사이이자 «누가 왕국을 먹여 살리나»의 맞수**) · 그 너머: 물길이 어느 땅에 닿는지는 비워 둠 |
| 구단이 놓인다면 | 강을 낀 경기장 · 다리와 배 위까지 관중 · 원정 응원단이 배를 타고 들어오는 그림 · 맞수 구도 = 땅길(동쪽) 대 물길(남쪽) |
| 정본과 닿는 줄 | 거울의 호수 · 반짝이는 샘(물의 출발) / **어긋날 수 있음**: 물이 남쪽으로 흐른다는 줄은 없다 · 배와 운송은 상인들의 거처(뱃놀이 · 거래수호 기사단)와 겹칠 수 있다 |
| 얻는 것 / 잃는 것 | 들판과 **한눈에 다르고** 밝다 · 물 반사는 그림이 화사하다 / 물 · 배 · 다리는 그릴 것이 많고, 무역 도시와 역할이 겹친다 |

### 안 2 — 볕드는 순례 비탈 · «수도를 올려다보는 등불의 계단»
| 칸 | 내용(⚑) |
|---|---|
| 가칭 | **한낮의 비탈** · 등불의 계단 · 꽃그늘 언덕 |
| 한 줄 분위기 | 순례길이 남문 밖으로 이어져 내려가는 볕 좋은 언덕 마을 — 조용하고 따뜻하고 **수도와 가장 닮은** 문 |
| 대표 풍경 | ① 계단식 과수밭과 흰 담장 ② 언덕을 오르는 긴 돌계단과 줄지은 등불 기둥 ③ 순례자 쉼터와 작은 종탑 ④ 계단 위로 올려다보이는 수도의 수정 탑 |
| 색 · 빛 · 날씨 | 한낮의 금빛 볕 · 흰 회벽 · 과일빛 · 짙고 또렷한 그림자 / 따뜻하고 마른 날 · 긴 오후 |
| 사는 이 | 과수 농부 · 등불지기 · 순례자 숙소 주인(종족은 짓지 않음) |
| 먹을거리 · 소품 | 볕에 말린 과일 · 꿀물 · 꽃차 / 손등불 · 순례 지팡이 · 과일 바구니 |
| 행사 | 등불 올리기(해 질 녘 계단에 불을 켬) · 수확 행진 |
| 이웃과의 관계 | 수도: 신앙과 예식의 길목(서임식 가는 길) · 새벽의 들판: **닮은 이웃**(들판 = 곡물과 가축 / 비탈 = 과일과 꽃) — 맞수라기보다 형제 |
| 구단이 놓인다면 | 비탈을 깎아 만든 계단 관중석 · 이긴 편이 등불 계단을 올라 수도로 가는 **승자의 행진** · 응원 = 등불 물결 |
| 정본과 닿는 줄 | 빛의 길 · 광화문 · 국교의 등불 / **어긋날 수 있음**: 빛의 길은 «광화문과 대성전 둘레»라고만 적혀 있어 문 밖까지 잇는 것은 늘려 읽은 것 · 들판과 농사로 겹친다 |
| 얻는 것 / 잃는 것 | 지금 세계의 결(등불 · 정원 · 순례)과 **가장 매끄럽게** 이어지고 그리기 쉽다 / 들판과의 대비가 약해 «왜 두 곳인가»가 흐려진다 |

### 안 3 — 왕국 끝의 큰 성문 · «여기서부터는 왕국이 아니다»
| 칸 | 내용(⚑) |
|---|---|
| 가칭 | **한낮의 성문** · 긴 볕 고개 · 마른 바람 문턱 |
| 한 줄 분위기 | 골짜기를 막아 선 큰 성벽과 문 — 왕국 밖에서 온 이들이 처음 발을 들이는, 낯설고 **북적이는 경계** |
| 대표 풍경 | ① 골짜기를 가로지른 높은 성벽과 겹문 ② 문 앞의 천막 장터와 나그네 숙소 ③ 성벽 위에 줄지은 깃발과 봉화대 ④ 볕에 달궈진 황토 고갯길 |
| 색 · 빛 · 날씨 | 달궈진 돌빛 · 황토 · 깃발의 또렷한 원색 · 길게 지는 그림자 / 마르고 바람 많음 · 낮은 덥고 밤은 서늘 |
| 사는 이 | 문지기 · 길잡이 · 여러 땅에서 온 나그네(종족이 **섞여** 보이는 곳 — 새 종족은 짓지 않음) |
| 먹을거리 · 소품 | 오래가는 길양식 · 여러 땅 음식이 섞인 노점 / 통행패 · 봉화 · 깃발 · 물자루 |
| 행사 | 문 여는 날의 큰 장 · 봉화 올리기 |
| 이웃과의 관계 | 수도: 수도의 방패 · 새벽의 들판: **뚜렷이 다른 땅**(들판 = 먹여 살린다 / 성문 = 지킨다) — 맞수 구도가 가장 세다 · 그 너머: 왕국 밖(어느 땅인지는 비워 둠) |
| 구단이 놓인다면 | 성벽이 곧 관중석 · «원정팀이 문으로 들어온다»는 입장 그림 · 깃발 응원 · 왕국 밖 기사단과 겨루는 자리로 넓히기 좋음 |
| 정본과 닿는 줄 | «변방 기사단들과의 갈등» · 왕국에 속하지 않은 땅이 있다는 줄 / **어긋날 수 있음**: «막는 벽»은 북쪽 방벽과 역할이 겹친다 · 요새의 무거움이 «어둡고 비장하게만 가지 않는다»와 부딪칠 수 있다(그래서 장터 · 깃발로 밝게 잡음) |
| 얻는 것 / 잃는 것 | 대비와 맞수 구도가 **가장 뚜렷**하고, 왕국 밖 이야기로 나가는 문이 된다 / 남쪽 너머가 무엇인지 곧 정해야 하고, 시작 지역치고 분위기가 세다 |

## 3. 세 안 견주기 (⚑)
| 견줄 것 | 안 1 물길의 나루 | 안 2 순례 비탈 | 안 3 큰 성문 |
|---|---|---|---|
| 분위기 | 활기 · 시끌벅적 | 따뜻 · 조용 · 경건 | 낯섦 · 북적이는 경계 |
| 새벽의 들판과의 대비 | 중간~큼(땅길 대 물길) | 작음(닮은 이웃) | 큼(먹임 대 지킴) |
| 리그 무대로서의 맛 | 배 타고 오는 원정 응원 · 다리 위 관중 | 등불 계단 · 승자의 행진 | 성벽 관중석 · 문으로 입장 · 바깥 팀과의 대항전 |
| 그리기 쉬움 | 중간(물 · 배 · 다리가 많음) | 쉬움(수도의 결을 이어 씀) | 중간(큰 구조물 하나가 중심 — 재질은 단순) |
| 지금 문서와의 거리 | 가까움(호수 · 샘) · 무역 도시와 겹칠 수 있음 | 가장 가까움(순례길 · 등불) | 멂(새 설정이 가장 많이 필요) |
| 서쪽을 남겨 두는가 | 남김 | 남김 | 남김(«왕국 밖»을 남쪽이 가져가면 서쪽의 쓰임이 줄 수 있음) |
- ⚑ 메인 컨셉 세션의 추천: **안 1**. 까닭 = 들판과 한눈에 다르면서 서로 주고받는 사이라 «같은 리그의 두 지역»으로 놓기 좋고, 밝다. 안 3은 맞수 구도가 가장 세지만 정해야 할 것이 가장 많다. — 고르는 것은 제제다.
- 안을 섞을 수도 있다(예: 안 1의 강 + 안 2의 등불 계단). 섞으면 그릴 것이 늘어난다.

## 4. 제제에게 물을 것 (취향 · 방향만)
1. **남쪽 관문은 새벽의 들판과 어떤 사이인가?** — (권장) 다르지만 주고받는 사이(안 1) · 닮은 이웃(안 2) · 뚜렷이 다른 땅(안 3). 얻는 것 / 잃는 것은 2절 안마다의 마지막 칸.
2. **남쪽 문 너머에 무엇이 있는가를 지금 정할 것인가?** — (권장) 지금은 비워 둔다(세 안 모두 그렇게 지음) · 지금 정한다(안 3을 고르면 곧 필요). 비우면 석환의 그림이 문 안쪽에만 머문다.
3. **이름을 «새벽 → 한낮»처럼 하루의 때로 이어 갈 것인가?** — (권장) 잇는다(동 새벽 · 남 한낮 · 서쪽은 뒤에) · 잇지 않는다(땅의 생김새로만 짓는다). 이으면 네 방위가 한 묶음으로 읽히지만, 북쪽(서리의 성채)은 그 결이 아니다.
