# 석환에게 — 세계관 · 리그 지역 · 기사단 한 장 (2026-11-22 초안)

> 지위: **⚑ 초안 — 제제 확인 전 · 석환 전달용 · 회의(11-22 🟡)의 방향에 맞춰 엮음.** 새로 정한 것은 없다 — 모든 줄은 `Docs/`의 줄에서 옮겼고(근거 = 6절), 이 장에서 엮거나 묶은 줄에는 **⚑엮음**을 붙였다. 작성: 메인 컨셉 디자인 전문가 · 팀장 검수(2026-11-22 — 금지어 0건 · 근거 줄 표본 8곳을 정본에서 대조 · 구단 색 등 «미정» 칸이 비어 있음 확인). 고침(2026-11-23 · 메인 컨셉 세션): 제제 결정 «은빛 물목»에 맞춰 2 ~ 6절을 다시 짬 — 옛 판은 이력의 커밋에 남아 있다 · 팀장 검수(2026-11-23 — 제제의 네 결정과 줄별 대조 · 금지어와 실제 리그 이름 0건 · 구단 · 강 이름 · 컵 규칙을 지어 넣지 않았음 확인).
> 표시 읽는 법: **🔵** 제제 확정(그대로 그린다) · **🟡** 팀 합의 · **〔볼트〕** 볼트 확정을 옮긴 줄(제제 확인 전 — 🔵 아님) · **⚑** 근거 문서가 초안·추론 · **⚑엮음** 이번에 엮은 것(바뀔 수 있다) · **⚑재료** 남쪽 관문 제안에서 가져온 그릴 거리(정해진 것 아님 — 바꿔도 된다) · **없음 — 정해야 함** 근거가 없어 비워 둔 칸(그리지 않고 기다린다).
> 순서는 회의에서 정한 대로: 세계관 → 리그가 진행되는 지역(**남쪽 «은빛 물목»** 🔵) → 그 지역의 리그와 기사단. 다른 게임의 이름은 쓰지 않았다.

## 1. 세계관 한 장면 — 게임을 켰을 때 무엇이 보이나

**한 줄**(⚑엮음): 스스로를 버리고 하나가 된 여신이 세계를 결계로 지키고, 여신을 닮은 여성들이 수련 끝에 «기사»로 승인받아 그 세계를 대신 지킨다 — 그리고 기사들은 기사단에 모여 **최고의 기사가 되려고 겨룬다.**

| 무엇 | 그림으로 옮길 말 | 표시 |
|---|---|---|
| 여신 | 세 주 신이 자아를 버리고 «하나가 된 신»이 됨 · 세상을 구역으로 나눠 **결계**를 침 · 악당이 아니라 **지쳐 버린 헌신자**(처단할 대상이 아니라 도와야 할 대상) | 〔볼트〕 · 톤의 선은 제제 «최우선» |
| 기사 | 여신이 자기 본래 모습과 닮은 **여성**에게 수호의 잠재력을 줌 → 한계를 넘는 수련 → 여신의 **승인(각성)** = 기사. 플레이어가 부리는 기사는 모두 여성 | 🔵 |
| 여왕 | 여신과 뜻이 이어진 대리자 · **서임식**에서 공적을 표창하고 여신에게 확인을 청함 | 🔵(서임식) · 〔볼트〕(대리자) |
| 나(유저) | 몸은 약한 **지휘관** = 자기 기사단의 **단장**(단장은 남성일 수 있음) | 🔵 |
| 기사의 몸 | 가는 몸에 큰 무기 · **가벼운 경갑**(목 · 심장 · 어깨 · 허벅지만) · 기본은 **맨머리** · 지치고 아파하는 표정은 규칙과 맞음 | 🔵(읽는 법은 ⚑) |
| 겨루는 것 | **«최고의 기사가 되려는 경쟁이 핵심 설정»** — 분위기는 여신 설정 + «참고작(달리기 경쟁 · 육성물 풍)» | 회의에서 오간 말(합의 아님 · `Docs/`에 없음) |
| 무엇을 걸고 겨루나 | 🔵 **리그(동부 리그 · 서부 리그)와 컵 대회가 있다**(제제 2026-11-23 — 3절). 상 · 순위 · 여신과의 관계는 **없음 — 정해야 함** | 🔵(리그 · 컵이 있다는 것까지) |

**분위기를 떠올릴 낱말**(모두 근거 문서의 낱말 · 고른 것은 ⚑엮음)
- **금속과 수정으로 장식된 탑** — 밤에는 마법의 빛으로 빛나는 수도 〔볼트〕
- **백화** — 빛나는 구체 + 세 갈래 불꽃(국교의 상징) · **해 질 녘 등불** 〔볼트〕
- **별빛을 머금은 식물의 정원 · 늘 잔잔해 도시가 비치는 호수** 〔볼트〕
- **마나 안개** — 안개 속에 벌어지는 차원의 틈 〔볼트〕
- **축제** — 수도의 방패 축제 · 들판의 화합 축제 · 화산의 대장장이 축제 〔볼트〕 · ⚑
- **가벼운 갑옷 · 맨머리 · 큰 무기** 🔵
- **어둡고 비장하게만 가지 않는다** — 여신은 지쳤지만 악당이 아니다 〔볼트〕

**게임 초반에 보여 줄 것** — 🟡 줄거리가 아니라 **세계관 소개 위주**(11-22 회의). 소개할 거리(⚑엮음 — 순서와 연출은 미정):
1. 여신이 하나가 되어 결계를 친 세계 2. 여성 → 수련 → 승인 = 기사 3. 여왕과 서임식 4. 나는 지휘관이자 내 기사단의 단장 5. 지역마다 모인 기사단들 — 그리고 큰 강의 땅에서 열리는 리그.
- 참고: `Docs/`에는 오프닝(마나 안개 속 차원의 틈에서 나온 몬스터를 처음 지휘해 물리침)과 첫 장 줄거리가 이미 있다 〔볼트〕 — 이것을 어떻게 둘지는 5절 (다).
- **첫 화면 그림이 무엇인지는 `Docs/`에 없다** — 없음 — 정해야 함(4절 물음 1).

## 2. 리그가 진행되는 지역 — 남쪽 «은빛 물목»

> 🔵 **리그의 무대는 수도의 남쪽에 새로 두는 지역, 별명 «은빛 물목»이다**(제제 2026-11-23). 아래 표의 🔵 줄은 제제의 말 그대로이고, **⚑재료** 줄은 남쪽 관문 제안(안 1)에서 가져온 «그릴 거리»다 — 정해진 것이 아니니 석환이 바꿔도 된다.
> 회의 의견(합의 아님 · 11-22): 한 지역 = 하나의 문화 · 환경 분위기를 가진 큰 단위(챕터). 지역이 모두 몇 개인지는 미정이다.

## 3. 은빛 물목의 리그와 기사단

> 회의에서 **논의된 방향**(합의로 올리지 않음 · 11-22): 기사단 = 프로 스포츠 구단처럼 고유한 색 · 유니폼 · 마크 · 역사 · 이야기를 가진 무리.
> 🔵 제제: **기존 기사단은 그대로 둔다 — 그들은 존재해야 한다**(2026-11-22) · **구단식 기사단은 남쪽 새 지역 «은빛 물목»에 새로 만든다**(2026-11-23 — 하루 전의 «새벽의 들판» 줄을 갈음). 석환이 «구단처럼» 그릴 대상은 **새로 만들 기사단**이고, 그것은 아직 하나도 정해지지 않았다.

### 3-1. 리그의 짜임
| 무엇 | 정해진 것(🔵 제제 2026-11-23) | 없음 — 정해야 함 |
|---|---|---|
| 동부 리그 | 있다 — 물길을 가운데 두고 나눈 한쪽 | 구단 수 · 구단 이름 · 겨루는 방식 · 한 철의 길이 |
| 서부 리그 | 있다 — 물길을 가운데 두고 나눈 다른 한쪽 | 〃 |
| 컵 대회 | 있다 | 누가 나오나 · 언제 열리나 · 꼴 · 상 |
| 크기 | 왕국에서 **가장 큰 리그**를 가진 지역 | 다른 지역에도 리그가 있는지(«가장 큰»에서 그렇게 읽을 수는 있다 ⚑ 읽기) |
| 기존 기사단(53곳) | 건드리지 않는다 | 리그나 컵 대회에 나오는지 |
| 유저의 기사단 | 유저 = 자기 기사단의 단장(🔵 앞서 정해짐) | 유저의 구단이 무엇인지 · 동부인지 서부인지(〔볼트〕에는 주인공이 여왕의 칙명으로 «빛의 고리 기사단»을 맡는다고 적혀 있다) |

### 3-3. 기존 기사단(참고) — 그대로 둔다 · 구단식으로 고쳐 쓰는 대상이 아니다

## 4. 석환에게 묻는 것 · 정해 주면 좋은 것
1. **첫 화면 그림**: «게임을 켰을 때의 한 장»으로 가장 그림이 되는 것은 무엇인가(수도의 수정 탑 · 서임식 · 강을 낀 경기장 등)?
2. **강을 낀 경기장과 응원**: 2-1의 재료(수문 · 겹다리 · 배 시장 · 배를 타고 오는 응원단) 가운데 그림이 되는 것과 버릴 것은 무엇인가? 은빛 물목의 한 장을 먼저 잡는다면 어느 장면인가?
3. **동부와 서부를 한눈에 가르는 방법**: 구단 색이 정해지기 전에 깔아 둘 규칙이 있다면 무엇이 좋은가(색의 온도 · 문양 · 강의 이쪽저쪽 풍경 · 깃발의 꼴 가운데)?

5. **마크의 단순함**: 전장의 작은 캐릭터와 포트레이트에서 마크가 읽히려면 얼마나 단순해야 하나 · 어디에 붙이나?
