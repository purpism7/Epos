**닫힌 물음**(물음 → 답)
- 36을 어디에 두나(㉮ 은빛 물목 안 · 도시 36 / ㉯ 영지가 왕국 여러 땅에 걸침 / ㉰ 도시 30 + 두 구단 도시 6) → 은빛 물목 안(2-6) · 두 구단 도시는 있되 고르지 않게(2-10).
- 영지 이름의 결(우리말 뿌리를 굴린 고유명 / 더 낯설게) → 지금처럼(6a-3).
- 두 결승의 승자가 마지막에 맞붙나 → 맞붙는다(2-9). 그 이름(가칭 셋: 물목 맞이 · 두 기슭의 날 · 은빛 한판) → 은빛 한판(2-11).
- 유저의 구단은 무엇인가(36곳 가운데 하나를 맡는다 / 서른일곱 번째 새 구단 · 둘째 판에서는 «한 자리를 비워 유저가 짓는다») → 하나를 맡는다(2-13). 고를 수 있는 구단(어느 것이든 / 처음에는 몇 곳만) → 어느 것이든(2-14).
- 구단이 셋인 도시를 둘까 → 둔다(2-12). «다라칸 까마귀»를 그대로 둘까 → 그대로(4-10). 아슬한 별명 넷(그물 · 나팔 · 제비 · 볕) → 그대로(4-10 — 그물은 뒤에 다시 봄). «윤슬라 등불»을 그대로 둘까 → 그대로(4-12).
- 단원과 팬을 따로 부르나 → 하나로 같다(4-11). 별명에 외래어를 섞어도 되나 → 우리말로만(4-13). 물건 별명을 어디까지 사람 꼴로 → 별명은 두고 부르는 말만(4-14). 다라칸의 고름(지킴이 / 곳간지기 / 열쇠 그대로 + 부르는 말만 지킴이 / «지키는 사람들»이라는 뜻의 외래어 꼴) → 열쇠 + 지킴이(4-15).
- 별명과 문장(별명은 대개 문장 이름 그대로 · 몇 곳만 애칭 / 모두 문장 이름 그대로) · 별명의 결(일 · 물건 · 동물을 섞는다 / 동물만 / 물건만) · 상징 경기장은 누구의 것인가(어느 구단의 것도 아닌 강 가운데 섬 / 한 구단의 홈) → 따로 답은 없었고 4-9 ~ 4-14의 잣대로 갈음됐다(상징 경기장은 제안대로 «어느 구단의 홈도 아님»으로 적혀 있다 ⚑).

- 첫 판의 여섯 구단(→ 둘째 판): 맏나루 기사단 → 맏나루 노잡이 · 겹다리 기사단 → 맏나루 겹다리 · 물레둑 기사단 → 물레둑 방아꾼 · 은등 기사단 → 은여울 등불 · 흰돛 기사단 → 갯머리 흰돛 · 윗수문 기사단 → 윗수문 수문지기.
- 셋째 판에서 별명 스물넷을 바꾼 까닭: «-꾼 · -지기»가 둘씩, 둥근 물건(가락지 · 조약돌 · 옹기)과 길쭉한 연장(삿대 · 지팡이 · 쐐기)이 몰려 있었다 → 문장 묶음에서 골라 서른여섯이 모두 다른 낱말이 되게. 그때 정체성을 지키려 이름만 바꾼 곳: 노잡이 → 사자 · 겹다리 → 짐말 · 생쥐 → 까마귀.
- 넷째 판: 거룻배 → 삿대 · 저녁해 → 소라(문장이 겹치지 않게). 깃털로 되돌리지 않은 까닭 = 기존 «큰 깃털 부족»과 엮여 보일 수 있다.
- 다섯째 판(4-9)에서 바꾼 열: 방아꾼 → 돌개바람 · 짐말 → 가라말(제제가 짚은 둘) / 골목개 → 삵 · 수탉 → 저울 · 멧돼지 → 오소리(«개 · 닭 · 돼지»는 그 말만으로 놀림이 된다) / 삿대 → 키잡이(«삿대질») · 조가비 → 밀물 · 소라 → 고래 · 은어 → 연어 · 삼단 → 동아줄(작고 약하게 들리거나 뜻이 흐리다). 짓다가 스스로 버린 것: 망치(기존 «영광의 망치 기사단»과 겹침) → 참나무 · 파도(기존 «노을파도 기사단») → 너울(한 부족의 전통 춤 «너울파도») → 밀물.
- 여섯째 판(4-10)에서 고친 셋: 연어 → 은어(제제 «은어는 그대로 둡니다») · 동아줄 → 송골매(줄은 어떤 말로 바꿔도 «끊어진다»가 따라붙어, 밧줄 고을의 정체성은 사연에 남기고 별명은 고갯마루의 사냥새로) · 밀물 → 갯바위(질 때마다 «썰물»이 된다).
- 일곱째 판에서 사람 꼴로 바꿨던 둘: 열쇠 → 지킴이 · 그물 → 어부(대안: 곳간지기 · 고기잡이 · 물수리 · 스스로 뺀 것: 파수꾼 — 기사단 정리 한 장에 나옴). 여덟째 판: 지킴이 → 별명 열쇠로 되돌리고 부르는 말을 지킴이로(🔵 4-15) · 어부 → 작살(⚑ 제제의 제안).

### 3-3. 부르는 말
- 여섯째 판(단원을 부르는 말 / 팬을 부르는 말 두 칸 — 🔵 옛 4-11): 단원은 대개 별명 그대로 · 비튼 말 셋(돌개 · 큰뿔 · 나팔수). 팬 말: 맞바람 · 솔숲 · 아랫고개 · 윗고개 · 버들내기 · 들사람 · 백조 · 맏이 · 발굽 · 한배 · 동녘 · 새벽장 · 삼밭 · 처마 · 곳간지기 · 떼 · 뭍사람 · 소금꽃 · 수문지기 · 에움길 · 가시 · 해맞이 · 달맞이 · 글벗 · 울림 · 윤슬 · 서녘 · 둥지 · 벌집 · 여울 · 뱃사람 · 반딧불 · 맨발 · 무리 · 먼바다 · 나이테. 그때 스스로 거른 것: 밤손님(도둑을 이르는 말) → 달맞이 · 모래알 → 맨발 · 도토리 → 나이테 · 닻줄 → 뭍사람 · 메아리(기존 «진실의 메아리 기사단») → 울림.
- 일곱째 판(하나로 — 🔵 4-11): 물건 별명에 사람 꼴 말을 붙임 — 저울 → 저울잡이 · 닻 → 붙박이 · 쇠북 → 쇠재비 · 등대 → 등대지기 · 나팔 → 나팔수 · 흰돛 → 뱃사람 · 볕 → 볕바라기. 스스로 뺀 것: 바람잡이(남을 꾀는 사람).
- 여덟째 판에서 다시 지은 셋: 붙박이 → **터주**(제제 «멋지지 않습니다») · 쇠재비 → **종지기**(뜻이 바로 오지 않는다) · 저울잡이 → **장꾼**(작살잡이가 생겨 «-잡이»가 몰린다). 볕바라기는 두었다.
