# 던전 한 장 (2026-11-09)

> 지위: 🔵 확정(기획자 직접 결정 2026-11-02~08) · 🟡 팀 합의(11-06 · 11-08) · ⚑ 임시(아레나 v0 껍데기). 갈음: 없음(첫 판).
> 한 줄: **던전은 파밍 구간이다.** 포탈(텔레포트)로 방을 옮기며 **노드맵을 한 칸씩** 나아가고, 전투 칸은 자동 전투, 이긴 칸은 잠긴다. 장비·유물을 얻어 장착한다. 유닛은 죽지 않는다.

## 1. 흐름 🔵
첫 화면(기사대전 / 던전 / 던전 이어하기) → **노드맵**(육각 칸 · 갈래 2 · 한 칸씩) → **인카운트**(적 배치를 보고 «전술 변경» · «편성» → «전투 시작») → **전투**(잡몹 → 마지막에 보스) → **결과 창** → **전리품**(고르기) → **장착**(무기 · 갑옷 · 반지) → **유물** → 다음 칸 … → 휴식/사건 칸(⚑) → 던전 끝.

## 2. 규칙 🔵
| 규칙 | 내용 | 왜 |
|---|---|---|
| 방 이동 | **텔레포트(포탈)**로 방을 옮긴다. 한 번 전투에 들어가면 **같은 맵**에서 끝까지(🟡 11-08) | 카메라 이동 없이 한 화면 |
| 맵 크기 | 던전 맵은 **카메라에 다 들어오는 크기** · 레이드 보스 맵만 더 크다(🟡) | 1초 층 |
| 일방통행 | **지나간 칸으로 못 돌아간다 · 이긴 칸은 잠긴다 · 같은 칸 연속 시도 금지** | 파밍 자리라 한 번에 «말도 안 되는 이득»이 없게 |
| 졌을 때 | 결과 창에 **«다시하기»**(그 칸 인카운트로 · 같은 시드면 같은 판이라 전술·편성을 고칠 수 있음) · **«물러나기»**(첫 화면) — ⚑ 밸런스 뒤 «다시하기» 허용 여부 재결정 | |
| 사망 없음 | HP 0 = 전투 불능. **기사 전원 HP 0 = 던전 공략 실패**. 장비는 못 가져감(🟡 «욕심을 부리다 죽으면») | 유닛 사망 없음(캐논) |
| 적 | **잡몹 1종 + 보스 1종**으로 시작(가장 작게) · 몬스터 병종은 ⚑ 잡몹 = 보병 · 보스 = 창병(표시만) | 던전 = 몬스터, 기사대전 = 기사 |
| 이어하기 | 던전 상태(지난 칸 · 장착 · 유물)를 저장 · 첫 화면 «던전 이어하기» · «처음으로»는 안 지움 · «던전» 새로 시작이 덮어씀 | |
| 좌우 | 모든 전투 화면은 **왼쪽 = 아군, 오른쪽 = 적** | 읽힘 |

## 3. 인카운트(전투 전) 🔵
- 내 기사 4열(왼쪽, 전투 화면과 같은 방향) · 적 격자(오른쪽, 보스는 크게 · 빈 칸은 옅게) · «유리 / 비등 / 불리» 막대(⚑ 표시만 — 전술을 바꾸면 움직임) · 단추 = «전술 변경» · «편성(성향·시드)» · **«전투 시작»(금색 하나)** · «돌아가기».
- 다음 판(🔵 결정, 아직 안 만듦): **드래그로 배치 조정 · 끌면 적 위에 상성(상극/피극) · 자리에 놓으면 누구를 노리는지 표적 선** — «왜 유리한가»가 읽히게.

## 4. 던전 컨셉 (🟡 팀 합의 — 확정 아님)
- 던전 안에서만 **«일시적으로 강해지는 에너지»**로 기사가 점점 강해진다. 장비를 얻으면 갖고 나갈 수 있지만, 욕심을 부리다 전멸하면 못 가져간다.
- **웨이브**: 보스전에 웨이브가 있고, 던전은 새 웨이브가 스폰된다(11-08). v0 에는 없음.
- 던전은 «유저가 가장 많이 할» 구간(파밍).

## 5. 몬스터 · 상성 (⚑ 미정)
- 기사끼리 = 클래스 상성 / 몬스터와는 **속성**으로 할 예정(기획자 구상 — 별도 속성 체계 문서 진행 중). 지금 v0 는 상성 없음.
- 던전 전투가 13초쯤에 끝나 연계가 거의 안 보인다 — 길이 조정은 보류(시연은 기사대전으로).

## 6. 기사대전과의 관계 🔵
- 기사대전 = 기사만 나오는 콜로세움(설정 AI 팀 vs 내 팀 · 지금은 친선전 · 1대1·토너먼트는 추후). 던전과 **전투 구조는 같다**(같은 시뮬·같은 화면) — 다른 것은 적(몬스터 vs 기사)과 앞뒤 흐름(전리품·장착·유물).
- 둘 다 PvE. 조작은 둘 다 나중(자동이 재밌어진 뒤).
