## 2. 병사 카드 (볼트 확정 · 옮김) [병사 카드 — 성장 · 진급 · 치료 2026-06-10]
| # | 줄 |
|---|---|
| 2-1 | 병사는 **«병사 카드» 한 종류**로 합친다(전열·후열·병종 구분 없이) · 병사 카드는 스스로 스킬이나 판단 능력치를 갖지 않고 **기사의 아래 칸에 끼워** 그 기사대의 화력 · 맷집 · 진형 안정을 올린다. |
| 2-2 | 등급(레벨은 이어서 셈): **일반 1~20 · 숙련 21~30 · 정예 31~40 · 근위 41~50** · 같은 최고 레벨 카드 2장 + 자원 → 다음 등급 1장. 키우기 = 연병장에서 부대 경험치를 원하는 카드에 넣는 «중앙 훈련» + 출격한 카드에 조금. |
| 2-3 | **공적 보고(전역)**: 다 키운 정예·근위 병사는 갈아 넣는 대신 **명예롭게 전역**하고 «무훈 증서»가 된다 → 기사의 한계 돌파 재료 · 기사 발탁 재화. |
| 2-4 | **영구 사망 없음**(병사 카드도 사라지지 않음) · 상태 = 정상 / 경상(출격 가능 · 품질 조금 감산) / 중상(출격 불가 · 한 번 눌러 치료) / 치료 중. |
| 2-5 | 기사대 품질을 글자 등급으로 보여 준다(근위 최고로 채우면 S — 그 위는 장비 · 결속 · 전술 특성 몫). |
