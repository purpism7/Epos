# 성향 · 판단 한 장 (2026-11-09)

> 지위: 🔵 확정(설계 볼트 캐논 — 판단 파이프라인 6단계 2026-06-15 동결 · 4단계 마나 예약 07-14 · 성향 10종 07-16 · 선택/실행 층 분리) · ⚑ 임시(아레나 v0 값). 갈음: 없음(첫 판).
> 한 줄: **성향은 «무엇을 고르나»만 기울이고, 능력치는 «얼마나 잘하나»를 정한다.** 기사의 행동은 6단계를 매 판단마다 거친다. «멍청함»은 버그가 아니라 능력치 차이의 표현이다.

## 1. 층 분리 🔵 — 선택(정책)과 실행(품질)은 다른 층
| 층 | 무엇을 정하나 | 어디서 |
|---|---|---|
| 성향(6층 정책) | 후보 중 **무엇을 고를지** 기울임 — 능력치를 바꾸지 않는다 | 2·3단계 |
| 임무 · 방침 · 외침(설정·지시) | 후보의 폭과 가중치 — 임무가 행동 반경과 표적 우선순위를 정함 | 2·3단계 |
| 능력치(2층 등) | 고른 행동이 **얼마나 잘 되나**(명중·방어·속도) · 판단력은 «아낌»과 상황 부합성 | 3~5단계 |
| 상태(5층 긴장 등) | 그 순간의 흔들림 | 3단계 가산 · 6단계 갱신 |

- 성격은 **확률적 기울임(기본 0.7)**이지 결정론이 아니다 — 잔여 0.3은 캐릭터 고유의 «살아 있음»(시그니처 예외). 다만 시뮬 전체는 **같은 시드 → 같은 결과**(난수는 시드에서).

## 2. 판단 파이프라인 6단계 🔵 (캐논 동결 2026-06-15)
| 단계 | 역할 | 관여 | 출력 |
|---|---|---|---|
| 1 지각 | 주변·전장에서 무슨 일이 나는지 수집 | 시야 · 예측력 · 집중력 | 위험 감지 · 표적 후보 · 스킬 각(밀집도) |
| 2 후보 생성 | 지금 할 수 있는 행동 목록 | **임무 · 성향 · 외침 · 쿨타임** | 공격 · 유지 · 추격 · 후퇴 · 엄호 · 스킬 발동 … |
| 3 선택 점수 | 후보에 점수 → 1순위 확정 | 판단력 · 침착성 · 명령준수 · 상태(사기·자신감) | 1순위 행동/표적 · 보류 후보 |
| 4 보류/발동 | 스킬·위험 행동을 **지금 쓸지, 아낄지** | 판단력 · 예측력 · 임무/지휘 숙련 | 즉시 / 보류(기본 공격으로 전환) |
| 5 실행 성공 판정 | 성패와 품질(피해 공식) | 무기술 · 방어술 · 힘 · 민첩 · 가속 · 침착성 | 명중 / 막힘 / 회피 / 치명 / 경직·넉백 |
| 6 결과 피드백 | 결과가 감정·관계·다음 판단에 반영 | 결과 데이터 · 사망자 유무 | 사기·임시 피로 갱신 · 신뢰/호감 경험치 · 숙련 · 다음 판단 캐시 |

- **점수식(3단계)**: `선택 점수 = 기본 점수(상황) + 성향 가산 + 지시 가산`. 예: «쐐기 돌격» 기본 50 + 전방 돌파 +25 → 75로 올라 선택. **성공 여부는 5단계(2층)가 따로 계산**한다 — 성향 가산은 «미묘한» 크기.
- **4단계 아낌(마나 예약, 07-14)**: 궁극기가 지금 쓸 수 있거나 임박하면 액티브의 유틸리티에 기회비용 페널티 — 판단력이 높으면 예약 성공, 낮으면 낭비. **«아끼는 중» 표시는 없음**(캐논 06-22 — 준비됨 빛만).
- 6단계가 갱신하는 피로 = **콘텐츠 안 임시 피로**(영구 피로는 전투 중 불변).

## 3. 성향 10종 🔵 (전투 성향 태그 — 기사마다 1개 · 2026-07-16 10종 확정)
| 성향 | 기울임(무엇을 고르나) | 표적 선호(파생 — 별도 태그 없음) | v0 꼬리표 |
|---|---|---|---|
| 결투 선호 | 강한 적 하나와 끝까지 | 강적·지휘관급 우선 | 결투 |
| 보호 우선 | 약한 아군 곁에서 막아섬 | 보호 대상에 근접한 적 우선 | 보호 |
| 후방 유지 | 아군 뒤에서 거리를 둠 | (후방 기준) | 후방 |
| 전방 돌파 | 앞을 지나쳐 적 뒤쪽을 노림 · 돌격 후보에 가산 | | 돌파 |
| 위험 회피 | 다치면 잠깐 물러섬 | | 회피 |
| 광역 스킬 선호 | 적이 뭉쳤을 때 궁극기(⚑ v0: 2명 이상 · 8초까지 기다림) | 밀집 집단 우선 | 광역 |
| 스킬 아끼기 | 결정적인 순간까지 궁극기를 아낌(⚑ v0: 아군 체력 40% 이하 때) | | 아낌 |
| 후퇴 거부 | **긴장이 높아져 물러서려는 순간에도 자리를 지킴**(※ 전장 이탈·퇴각은 게임에 없음) | | 거부 |
| 추격 집착 | 적이 무너져 도망칠 때 **대형을 벗어나 끝까지 쫓음** | 무너진·도망치는 약체 우선 | 추격 |
| 라인 고수 | 같은 상황에서도 **자리를 지킴**(추격 집착과 쌍) | | 고수 |

- 추격은 6층(마음 — 쫓을까 말까) · 따라잡나는 2층 속도(다리) — 겹치지 않는다. 추격 ≠ 활동력(아군을 도우러 가는 이동) ≠ 대담성(위험 교전 **판단 품질**).
- 성향이 화면에 보이는 길: 머리 위 성향 그림 · 지금 노리는 상대 선 · 행동이 바뀔 때 짧은 말풍선(4초) · 전투 기록 줄.

## 4. 임무 · 방침과의 관계 🔵
- **임무(칸이 정함)**가 2단계 후보의 폭과 3단계 표적 우선순위를 정한다 → 성향은 그 안에서 기울인다. 성향이 임무와 맞으면 **+**, 어긋나면 **−**를 설정 화면에 보여 준다(예: 라인 가드에 전방 돌파 성향 = «더 공격적으로 행동합니다» 경고).
- **방침 3종**(공격형·방어형·유연형)은 팀 전체의 기본 점수를 기울인다 · **외침**은 그 위에 잠깐 얹는 지시 가산(명령준수가 수용률).
- 플레이어는 성향을 바꾸지 못한다 — 누구를 어디에 세우고 무엇을 맡기느냐로 다룬다(세팅의 재미).

## 5. v0 와의 대응(⚑)
- v0 는 6단계를 축약한 판단기(몇 초마다 다시 고름 · «판단 보기 J»로 이유를 봄)로 10종 성향 전부를 쓴다. 궁극기 사용 규칙 = 성향별(`now` / 뭉침 `cluster` / 아낌 `save`).
- 임무 6종(선봉장 · 라인 가드 · 수호대 · 사수 · 엄호대 · 사격조율관)과 후보 3종(돌격대 · 지원 · 후위 요격 ⚑)이 열·칸으로 배정된다.
- 능력치 7층·2층 항목(무기술·방어술·일대일·다인 등)은 v0 에 **없다** — 5단계는 단순 수식.

## 6. 하지 말 것 🔵
- 성향이 능력치를 바꾸는 것(성향 = 선택만).
- 같은 뜻의 태그를 두 벌 만드는 것(표적 선호는 성향에서 파생).
- 상태이상·붕괴 게이지를 임의로 새로 확정하는 것(사기·동요·패주는 별도 설계 뒤).
- 플레이어가 스킬·행동을 수동으로 고르게 하는 것(자동 전투가 먼저).
