# 클래스 · 무기 한 장 (2026-11-08)

> 지위: 🔵 확정(설계 볼트 «클래스 8계열» 2026-06-15 + 기획자 직접 결정 2026-11-04~08) · 🟡 팀 합의(11-06) · ⚑ 임시/미정. 갈음: 없음(첫 판).
> 원칙 한 줄: **무기 종류 = 클래스.** 플레이어는 무기를 보고 클래스를 안다. 아이콘도 무기 특징으로.

## 1. 9계열 (3축 = 위치 · 속성 · 역할)
| 계열 | 축 | 전장 역할 | 2차 세부직업(영웅 전용) |
|---|---|---|---|
| **파이터**(검·방병) | 전열 · 물리 · 근접 · 최전열 | 라인 보호(붙잡기) | 방패기사 · 검투사 · 바바리안 |
| **랜서**(창병) | 전열 · 물리 · 근접 · **돌격** | 돌격 · 우회(기병의 카타르시스) | ⚑ 나중 |
| **아처**(궁병) | 후열 · 물리 · 원거리 | 사격(거리 두기) | 저격수 · 트래퍼 · ⚑ 셋째 미정(옛 «암살자»는 뺌) |
| 드루이드 | 전열 · 마법 · 근접 | | 변신술사 · 정령 주술사 · 자연의 수호자 |
| 위저드 | 후열 · 마법 · 원거리 | | 화염술사 · 냉기술사 · 시간술사 |
| 몽크 | 전열 · 보조 · 근접 | | 권법가 · 오라 수호자 · 치유 몽크 |
| 바드 | 후열 · 보조 · 원거리 | | 음유시인 · 하모니스트 · 음파술사 |
| 클레릭 | 후열 · 보조 · 원거리 | | 성기사 · 빛의 사제 · 구원자 |
| 샤먼 | 후열 · 보조 · 원거리 | | 워락 · 주술사 · 영혼 사냥꾼 |

- «보조» = 버프 · 디버프 · 상황 조작. 1차 직업 = 병사 전용(Lv.1~34) · 2차 세부직업 = 영웅(기사) 전용(Lv.35~60, 수집·전직 테마).
- 10번째 «단검(도적/암살자 — 우회·은신·빠름·낮은 체력)» 계열은 **나중에 다시 연다**(🔵, 지금은 없음).

## 2. 무기 매칭 🔵
| 클래스 | 무기(2벌) | 메모 |
|---|---|---|
| 파이터 | 스몰 쉴드 + 숏소드 **또는** 빅 쉴드 + 롱소드 | 방패·검 한 벌 |
| 랜서 | 장창 **또는** 단창 | |
| 아처 | 단궁 **또는** 장궁 | |
| 마법·보조 6계열 | ⚑ 미정 | 무기 2벌 원칙을 그대로 적용할지 뒤에 |
- **다른 클래스의 장비는 착용 불가**(🟡 팀 합의 11-06).
- 액션 모션은 **클래스 공통**, 무기 길이에 따라 **속도만 조정**(🔵) — 모션을 무기마다 새로 만들지 않는다.
- 연타(기본 공격 묶음)는 무기가 정한다 — 약-약-약(빠름) / 강-강(넓지만 끝 딜레이) 같은 구성. 자동으로 이어진다(버튼 연타 아님).

## 3. 병종 ↔ 계열 🔵
| 병종 | 계열 | 식별 도형 |
|---|---|---|
| 보병 | 파이터 | 사각형 |
| 창병 | 랜서(신설 — 8계열에 없던 돌격 딜러) | 삼각형 |
| 궁병 | 아처 | 원형 |
| 마법병 | 위저드 등 | |
- 8계열 전부 병종화 → 병사는 지휘하는 영웅의 계열(병종)을 그대로 따른다(영웅과 일체감 · 복잡성 줄임).

## 4. 상성 🔵 (가위바위보)
- 병종(상위): **보병 > 궁병 > 창병 > 보병**
- 클래스(하위 세부): 파이터 > 아처 > 위저드 > 파이터 · 드루이드 > 위저드 > 몽크 > 드루이드 · 바드 > 샤먼 > 클레릭 > 바드 · 파이터 > 몽크 > 아처 > 파이터
- 랜서(창병)의 클래스 상성은 ⚑ 미정(병종 상성이 상위). 몬스터와의 상성은 **속성**으로 할 예정(⚑ 미정).
