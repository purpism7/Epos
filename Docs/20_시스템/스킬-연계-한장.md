# 스킬 · 연계 한 장 (2026-11-08)

> 지위: 🔵 확정(설계 볼트 캐논 2026-06-15·07-14 + 기획자 직접 결정 2026-11-04~08) · 🟡 팀 합의(11-06 «연계기 통과») · ⚑ 임시(아레나 v0 시연값). 갈음: 없음(첫 판).
> 한 줄: **기사는 스킬 2종(액티브 1 + 궁극기 1)만 가진다. 연계기는 스킬이 아니라 «두 기사의 관계»에 붙는다. 호응은 동시에 일어나는 «동작»이지 두 번째 궁극기가 아니다.**

## 1. 스킬 2종 🔵
| | 액티브 (옛 일반기) | 궁극기 (옛 필살기) |
|---|---|---|
| 몇 개 | 기사마다 1 — 클래스 특징 기술 | 기사마다 1 — 큰 기술, **역전 장치** |
| 자원 | 마나 + 쿨타임 | 마나 + 쿨타임(더 비쌈) |
| 누가 쓰나 | 기사가 스스로(판단 파이프라인) — **플레이어 수동 사용 없음**(🟡 «수동 사용은 맞지 않다») | 같음. 성향에 따라 쓰는 때가 다르다 |
| 화면 | 머리 위에 **스킬 이름 글자** | **컷인**(왼쪽 위 포트레이트 + 말풍선 + 금색 섬광) |
| 예고 | 왼쪽 세로 포트레이트의 아이콘 · 쿨 고리 | 같은 자리 · 준비되면 빛 |
| 2차 전직 | — | 전용 **패시브**가 더해져 특징을 강화(🟡) |

- **아낌(판단 4단계, 🔵 캐논 07-14)**: 궁극기가 (a) 지금 쓸 수 있거나 (b) 쿨타임 해제가 임박하면, 액티브 사용의 유틸리티에 **기회비용 페널티**를 곱한다. 관여 능력치 = 판단력(아끼기) · 예측력(적 방어 타이밍) · 임무/지휘 숙련도. «마구 쏘다 궁극기를 못 쓰는 멍청함»은 버그가 아니라 **능력치 차이의 표현**이다.
- **보류 피드백 없음(🔵 캐논 06-22)**: «아끼는 중»을 머리 위 말풍선 같은 세부 표시로 알리지 않는다 — 준비됨 빛만. (v0 카드의 «준비됨» 표기는 Human Gate 뒤 다시 본다.)
- 공포 같은 상태이상은 **스킬이 거는 CC**(가해 출력 저하 + 판단 왜곡)이지 사기에서 오지 않는다(🔵 캐논).

## 2. 연계기 🔵 — 스킬 칸이 아니라 «짝»에 붙는다
| 원리 | 규칙 |
|---|---|
| 어디에 붙나 | **두 기사의 관계(짝 A×B)에 1건.** 편성에서 «누구와 누구를 같이 내보내나»가 조건이 된다 |
| 두 층 | **특화 짝** = 특별한 연출·전용 이름 / **범용** = 관계만 있으면 기본 연출 |
| 특화의 두 축 | ① **인물 특화** — 두 캐릭터 전용(캐논 선례: 두 기사의 «조건부 연계기» — 한쪽 이능력이 발동 중이고 다른 쪽이 인접하면 **확정 발동**, 해금은 서사의 화합 뒤, 3인 연계는 가능성만) ② **기술 연관 특화** — 스킬 조합이 호응의 종류를 정한다(검 내려찍기 × 메이지: 무속성 = **피해 영역 확장** / 불 속성 = 찍은 자리에 **불 피해 + 불 연출**) |
| 인연 | 관계가 깊어야 발동(노력·특별함의 증거). 지금은 켜짐/꺼짐뿐, 수치는 ⚑ 나중 |
| 왜 | 플레이어가 기사 구성 · 진영 배치 · 기사끼리의 관계와 성향 어울림에 관심을 갖게(🔵 기획 의도) |

## 3. 호응 🔵 — 동시에 일어나는 «동작»
| 규칙 | 내용 |
|---|---|
| 순간 | A가 궁극기를 **쓰는 순간**(발동 틱) |
| 조건 | 관계 있는 B가 **근처**(⚑ 3칸 · 검×메이지는 4칸 — 메이지가 뒤에 서서) · 살아 있고 그로기 아님 |
| 동작 | **B의 궁극기가 아니다.** 비용 · 쿨타임 **0**. 근처에 없으면 일어나지 않는다. 적은 호응하지 않는다(현 단계) |
| 종류 | 타격형 궁극기 → **따라 찍기**(⚑ 0.5배, 같은 조준점) · 보호형/특화 → **넓히기**(⚑ 범위 1.5배, 피해 그대로) |
| 방향 | 특화는 한 방향으로 정의(검 궁극기 → 메이지 호응). 반대 방향은 범용 규칙 |
| 연출 | 호응 기사의 포트레이트가 **참여 순서대로 쌓이고**, 연계 전용 말풍선(기사마다 1줄 ⚑) · 특화는 전용 이름 배너 · 두 기사 사이 금색 끈 |
| 결과 창 | «연계 n회» 한 줄 · 결정적 장면 맨 위 |
| 수치 | 회의에서 나온 «5배»는 예시이지 값이 아님. 값은 전부 ⚑ |

v0 시연 짝(⚑): 검 기사 × 메이지(마법 기사) = **특화 «공명 강타»(넓히기)** · 검 × 랜서(창 기사) = 범용(따라 찍기) · 랜서 × 메이지 = 관계 꺼짐(«관계가 없으면 안 따라온다»를 보여 주려고).

## 4. 데이터 꼴 (v0 — 프로그래머 참고, 이름은 바꿔도 됨)
- 기사 종류마다 `active`(이름 · 쿨 · 사거리) · `ult`(이름 · kind = strike|guard · 조건 · 마나 · 쿨).
- `bonds.json`: 짝 목록 — `a`, `b`, `enabled`, `special`(없거나 { `name`, `kind`: expand|follow, `direction`: a→b }), `near`(칸).
- 호응 판정은 **순수 함수**(입력: 발동 기사 · 짝 목록 · 위치 · 상태 → 출력: 호응자 목록 + 종류). 같은 시드 → 같은 결과. 연출은 이벤트(«궁극기 발동» · «호응» · «적중»)를 받아서만 그린다 — 시뮬을 건드리지 않는다.
- 새 규칙은 **스위치**(켬/끔)로 두어 옛 골든 시험이 그대로 통과하게 한다.

## 5. 하지 말 것 🔵
- 연계기를 세 번째 스킬 칸으로 만들지 않는다. 호응에 비용·쿨을 붙이지 않는다.
- 궁극기+궁극기를 동시에 맞추라고 요구하지 않는다(실시간 이동 전투라 불가능에 가깝다).
- 모든 짝에 특화를 주지 않는다 — 발동 상황이 적어진다. 특화는 «서로 시너지가 좋도록» 설계한 짝에만.
- 플레이어가 스킬을 수동으로 누르는 구조로 가지 않는다(자동 전투가 먼저).
