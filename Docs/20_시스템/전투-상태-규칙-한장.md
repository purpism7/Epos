# 전투 상태 규칙 한 장 — 쓰러지면 어떻게 되고, 무엇이 없나 (2026-11-16)

> 지위: **볼트 확정(옮김 — 제제 확인 전)** — 🔵가 아니다. 제제가 줄 번호로 «맞다»고 하면 🔵 후보. 볼트 확정 노트(`decided`) 3건에서 옮기고 `Docs/`의 🔵와 대조했다. 작성: 문서 전문가 · 팀장 검수(2026-11-16 — 볼트 원문 표본 대조 · 근거 노트의 확정 표시 확인 · 금지어 0건). 갈음: 없음(첫 판). 새로 정한 것 없음.
> 이 장에서 찾을 수 있는 것: ① 체력 0이 된 기사는 어떻게 되나(쓰러짐 · 되살림 없음) ② 전장 이탈·아군 피해처럼 **없는 것** ③ 공포 · 역전 · 피로가 어떤 층에서 움직이나.
> 근거 적는 법: 줄 끝 `[ ]` = 볼트 노트 제목(풀어 적음). «전투 상태» = «전투 상태 — 쓰러짐 · 물러남 없음 · 공포 · 역전 · 피로 2층»(2026-07-14 · 제제 확정 9건). 볼트 본문의 «필살기 · 일반기»는 지금 이름 «궁극기 · 액티브»로 옮겼다(용어표 §5 🔵).

## 1. 체력 0 — 쓰러짐 (볼트 확정 · 옮김)
| # | 줄 | 근거 |
|---|---|---|
| 1-1 | 기사의 체력이 0이 되면 **쓰러진다**(쓰러지는 동작 뒤 전장에서 빠짐). 그 전투에는 다시 참여하지 못한다. «사라짐»은 전장에서의 일이고, 기사는 보유 목록에서 사라지지 않는다. | [전투 상태 ①] |
| 1-2 | 쓰러짐은 **전투 중에 되돌릴 수 없다** — 전투 중 쓰러진 기사를 일으키지 못한다(전투가 끝난 뒤 돌아오는 것은 별개). **치유는 되살리기가 아니라 막기**다. | [전투 상태 ③] |
| 1-3 | 다치거나 쓰러진 뒤의 상태(경상 · 중상 · 치료 중)는 5층 «부상»이 맡는다 — 품질 감산이나 편성 제한으로 작동. | [5층 상태값 «부상»] |

## 2. 없는 것 (볼트 확정 · 옮김)
| # | 줄 | 근거 |
|---|---|---|
| 2-1 | **부대가 전장을 떠나는 퇴각은 없다.** «사기가 떨어져 겁먹고 부대가 물러난다»는 길은 기각됐다 — 사기는 **잠깐 성능을 낮추는 것**으로만 작동. 까닭(제제): 소규모 전장에서 전선이 무너지거나 물러나면 사격 부대가 보호받는 상황이 거의 없어지고, 부대마다의 개성을 설계하기 어려워진다. | [전투 상태 ② · 6절] |
| 2-2 | **개인이 잠깐 당황해 피하는 것은 있다** — 5층 «긴장»에서 오는 «도망»은 한 사람의 전장 안 일시 회피이지 전장 이탈이 아니다. «부대가 물러나는 것은 없고, 개인이 잠깐 당황해 회피하는 것은 있다.» | [전투 상태 ⑨ · 2절] |
| 2-3 | **아군 오사(아군을 맞힘)는 없다 — 전부에.** 어떤 공격·스킬(광역 포함)도 아군에게 피해를 주지 않는다. 궁병 투사체에만 있던 규칙을 모든 병종·모든 스킬로 넓힘(제제 2026-07-16 «오사 없음을 전역 확정한다»). | [아군 오사 없음 — 전역 확정] · [궁병 발사 각도 고정] |
| 2-4 | 그래서 표적 고르기의 «아군 광역 피해 위험» 축은 **버렸다**(늘 0인 죽은 축). 광역 표적은 «적이 얼마나 뭉쳤나»만 본다 — 아군이 뒤엉킨 난전에서도 광역기를 망설이지 않는다. | [아군 오사 없음 — 함의] |

## 3. 역전 · 공포 · 피로 (볼트 확정 · 옮김)
| # | 줄 | 근거 |
|---|---|---|
| 3-1 | **역전 장치 = 궁극기.** 기사 스킬 2종 가운데 궁극기가 뒤집기의 발판이다. 스킬은 **마나 + 스킬마다 쿨타임**으로 쓴다. | [전투 상태 ④ · ⑥] |
| 3-2 | 마나·쿨타임은 열세와 상관없이 차오르므로, 역전은 **판단에 걸린다** — 3단계 궁극기 점수에 «아군 열세»가 들어가야 한다(새 축 없이: 5층 긴장 · 2층 승부욕). 볼트의 정의: «역전 = 승부욕이 긴장을 이기고 궁극기를 쓰는 순간». | [전투 상태 4절] |
| 3-3 | **공포 = 스킬로 걸리는 상태이상**(사기에서 오지 않음). 효과 = **주는 피해가 줄고 + 판단이 비틀린다.** 피해 감소는 필수 안전장치(판단만 비틀면 «피하다 덜 맞는» 이득이 되어 공포를 좋아하게 됨). 버티는 능력치 = 침착성. 5층 긴장(전황이 만드는 마음)과는 다른 축. | [전투 상태 ⑤ · 5절] |
| 3-4 | **피로 = 2층**: 영구 피로(콘텐츠 참여로 쌓임 · 전투 중엔 그대로) + 콘텐츠 안 임시 피로(활동으로 쌓이고 콘텐츠가 끝나면 사라짐). 끝나면 콘텐츠별 계산값만큼 영구 피로가 오른다(볼트의 예: 20 → 30). 전투 무대에 들어가는 순간 피로는 변하지 않는다. | [전투 상태 ⑦ · 3절] · [5층 상태값 «피로»] |
| 3-5 | 피로는 **아주 약하게** 쌓이게 한다(수치 올리기는 밸런스 때). 영구 피로의 주 회복처 = 주점(여관). | [전투 상태 ⑧] |
| 3-6 | 기각·보류(볼트 그대로): 사기에서 오는 겁먹음·부대 후퇴 = **기각** · 역전 장치로서의 지원군 = 보류 · 지형 높낮이 보너스 = 보류(공성전 밖엔 높낮이 없음) · 피로 없애기 = 철회(2층으로 나눠 풂). | [전투 상태 6절] |
