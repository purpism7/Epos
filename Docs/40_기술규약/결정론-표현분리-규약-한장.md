## 1. 규약 7조 🔵 (제제 2026-11-16 — ~~볼트 확정 · 옮김~~) [결정론 · 표현 분리 아키텍처 규약 2026-07-15]
| # | 줄 |
|---|---|
| 1-1 | **시뮬은 표현을 모른다.** 시뮬 계층 = 판정 · 확률 · 상태 전이(판단 6단계가 여기 산다). 표현 계층 = 그림 · 애니메이션 · 파티클 · 카메라 · 소리 · 해설 글 · 화면. **표현을 위해 시뮬 로직을 고치지 않는다** — 연출이 아쉬우면 표현 계층에서 푼다. |
| 1-2 | **결정론을 더럽히지 않는다**: 시뮬은 **주입된 난수 하나만** 쓴다(전역 난수 금지) · 시뮬 한 걸음 안에서 이벤트를 바로 쏘지 않고 **버퍼에 모았다가 걸음이 끝난 뒤** 내보낸다 · **표현용 난수는 시뮬 난수와 완전히 따로** · 유닛을 도는 순서는 **안정된 번호 순**(객체 주소·해시 순서에 기대지 않음). |
| 1-3 | **이벤트 키 = 시뮬과 표현 사이의 유일한 약속.** 시뮬이 넘기는 것은 가벼운 이벤트(`{키, 틱, 주체, 대상, 좌표}`)뿐 · 키는 **결과의 뜻**만 담고 물리·문자열·연출을 담지 않는다 · 표현은 키로 표를 찾아 애니·소리·해설·카메라를 고른다. |
| 1-4 | **표현은 데이터가 이끈다** — 이벤트 키 하나 = 표현 자료 하나(애니 · 소리 · 해설 문장 묶음 · 하이라이트 표시 · 가중치 · 지연). 해설 글은 **문장 틀 + 변수 바꾸기**(코드에 문자열을 박지 않음). |
| 1-5 | **다시 보기 = 시드 + 입력 기록 재생**(영상 0바이트) — `{시드, 편성, 유저 개입 기록}`만 저장하면 재현된다. 하이라이트는 이벤트의 **중요도 표시**로 고른다(표현 계층 몫). |
| 1-6 | **수치는 전부 밖으로 뺀다 · 참고작 수치를 박지 않는다** — 참고작에서 가져오는 것은 **구조와 원리**뿐, 값은 우리가 재서 정한다. 모든 밸런스 값은 자료로 빼서 화면 없는 일괄 시뮬로 재고 맞춘다. |
| 1-7 | **회귀 시험 = 같은 시드 → 같은 결과(바이트까지)** — 표현·화면 작업 뒤에도 같아야 한다. 깨지면 표현이 시뮬을 더럽힌 것. 시뮬 행동을 **일부러** 바꾼 때는 «의도한 기준 바꿈»으로 적고 기준값을 새로 잡는다. |
- 1-8 한계(볼트가 스스로 적음): 결정론은 **같은 실행 파일 · 같은 기기 구조** 안에서만 바이트까지 같다고 볼 수 있다 → 서버와 기기 사이 재현(서버 검증 · 대전)은 **서버가 판정 + 다시 보기 재생** 구조가 따로 필요하다. 결정론은 자동 전투가 맞아떨어지는 **필요조건이지 충분조건이 아니다**(방치용 축약 계산은 별개 문제).
- 1-9 볼트의 «뒤에 정할 것»: 이벤트 키 목록 초판 · 회귀 시험 틀과 기준 시드 · 서버가 어디까지 판정하나.
