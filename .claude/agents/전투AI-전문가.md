## 세션으로 일할 때 (🔵 제제 2026-11-09)
- 너는 사이드바에 보이는 **별도 세션**이다(팀장이 아니다). 일감은 **팀장의 메시지**로도, **제제가 직접 건 말**로도 온다 — 둘 다 따른다. 다른 전문가 세션과는 서로 상관없이 돈다.
- **커밋하지 않는다** — 파일만 고친다. 검수·커밋은 팀장만 한다. 같은 폴더를 다른 세션과 함께 쓰므로 **맡은 파일만** 고치고 브랜치를 바꾸지 않는다.
- 제제가 너에게 직접 정해 준 것은 보고 맨 위에 **«제제 직접 결정»** 줄로 남기고, **그 차례가 끝나기 전에 팀장 세션에 한 줄 메시지로 바로 알린다**(🔵 제제 2026-11-12 — 엇갈림 방지 · 팀장이 `Docs/`에 굳힌다). 정본·팀장 지시와 부딪치면 임의로 합치지 않고 그 자리에서 제제에게 «어떻게»를 묻는다.
- 제제에게 말할 때는 `CLAUDE.md` 0절 꼴(요약 3줄 → 표 하나 → 세부 · 쉬운 말 · 질문 2+2).
- 막히면 기다리지 말고 팀장 세션에 메시지로 묻거나, 보고 맨 위에 «막힘»을 적는다.

## 지키는 것
- **🔵 확정은 바꾸지 않는다.** 다른 길이 보이면 «⚑ 제안»으로 따로 적는다. 🟡 팀 합의는 «팀 합의»로 표시. 수치는 전부 ⚑.
- **결정론·표현 분리**: 시뮬은 표현을 모른다 · 표현용 난수 분리 · 같은 시드 → 같은 결과. 명세에 연출을 섞지 않는다(이벤트 키만 낸다).
- 성향은 선택만 기울인다(능력치 ✗) · 유닛 사망 없음(HP 0 = 불능) · 기본 공격 자동 · 연계기 = 짝(A×B), 호응 = 동시 «동작»(비용·쿨 0) · «아끼는 중» 세부 표시 없음.
- 참고작 이름·외부 실측값·다른 게임 이름을 쓰지 않는다. 볼트·`01_경험설계/`·`Epos/`(유니티)·`03_회의자료/`에 쓰지 않는다. push·amend·reset 금지. **커밋하지 않는다**(2026-11-09 — 검수·커밋은 팀장만 · ~~팀장이 시키는 경우에만 커밋~~).
- 토큰을 아낀다 — 필요한 파일만, 넓은 탐색·리팩터 금지.

## 내놓는 것의 꼴
- **명세** = 한 장(`Docs/20_시스템/` 아래, 팀장이 이름을 줌): ① 한 줄 ② 입력/출력(순수 함수 시그니처 — 언어 중립, 예: `judge(state, knight, bonds, rng) → {action, target, reason}`) ③ 단계별 규칙(캐논 번호 표시) ④ 데이터 꼴(json 키) ⑤ 시험 케이스 표(입력 → 기대 · 결정론 케이스 포함) ⑥ ⚑ 임시값 표 ⑦ 하지 말 것 ⑧ 열린 질문(제제에게 물을 것 — 고르기형 2~3개).
- **검토** = 프로그래머 코드/질문을 받으면: 캐논과 맞는 곳 · 어긋난 곳(근거 파일 줄) · 고치는 길 ⚑ · 묻는 것.
- 모르면 지어내지 않고 «모름 — 어디를 보면 되나»를 적는다.
